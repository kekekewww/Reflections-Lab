## 共用輸入與限制

- **number**：pointer focus、keyboard direct entry、Enter commit、blur commit、Escape revert、valid fractional finite、min/max、outside range、empty/nonfinite、IME/locale retention。並非每欄都適用全部方法；NOT_APPLICABLE需給source理由。
- **select**：pointer choose、keyboard Arrow/Enter、each existing enabled option、disabled option reason、cancel/undo or restore when applicable。options來自finite catalog；動態資產依fixture catalog與stable ID。
- **button**：pointer click、Tab+Enter/Space activation、enabled prerequisite、disabled reason/no mutation、async overlap/cancel when applicable。只點擊不等於Host成功，須assert畫面/資料/檔案結果。
- **details-and-scroll**：pointer toggle、keyboard activation、focus and reachable content、scroll where overflow。只讀資料不可當成可編輯參數。
- **canvas**：pointer source gesture、keyboard/explicit alternative、cancel/blur/release、selection synchronization。Headless無原生pointerlock證據須明示；替代輸入不冒充native lock。
- **help**：caller reach and correct content、shared hover/focus/Escape/touch、disabled fallback。generic互動可共用；每caller可達/內容不得因此省略。
- **file**：valid own fixture、malformed/unsupported、boundary size if feasible、same file retry、cancel、atomic old state preservation。音檔權利checkbox明示；不引入商業素材。

HelpTip的generic hover/focus/Escape/touch/disabled fallback可共用；每個caller的可達與內容仍需映射。Section help也列入。PanelDivider包含drag、箭頭、Home、doubleclick與隱藏焦點排除。FPS真lock與免鎖定替代操作分開，blur/hidden/OS輸入沒有直接事件證據時不冒充已驗。

目前沒有Meta model/key/budget/context editors、Performance refresh、Mapping clamp toggle或曲線SVG drag；readonly metric/provenance/progress不是可編輯參數。Fixed/kinematic控制權、真空、busy/invalid/stale等合法前提與外部account/hardware gate不因新增功能要求而移除。
