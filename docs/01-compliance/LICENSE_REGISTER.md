## 登錄與發行關卡

每件採用資產記錄 `asset_id`、原作者、官方 URL、版本／commit、取得 UTC、SHA-256、license 原文位置、修改、用途、散布範圍、必要 attribution、競賽狀態。不可只寫套件的 SPDX 縮寫而省略原文與第三方元件。

`package-lock.json` 是可重現依賴來源；[DEPENDENCY_LICENSE_INVENTORY.json](DEPENDENCY_LICENSE_INVENTORY.json)（schema 2）為本機已安裝套件的 metadata／授權檔 hash 快照，亦記 lockfile integrity 及獨立的可選本地工具。其結果不是法律核准，也未判斷每個檔案的全部權利。未來公開 build 需依實際 bundle／native link／資料檔重做盤點，產生發行用 `THIRD_PARTY_NOTICES`，並核對競賽接受範圍。

Phase 1 歷史快照為 88 個 installed packages，MIT 61、Apache-2.0 14、BSD-2-Clause 6、BSD-3-Clause 2、ISC 4、BlueOak-1.0.0 1；全部有 manifest license 欄位。部分套件未由根目錄授權檔名掃描找到匹配檔案，標為 `license_files: []`，只表示 `ARTIFACT_NOT_DETECTED`；可能須查 README、內嵌檔頭或上游發行包，不能推定沒有授權或已免除 notices。
