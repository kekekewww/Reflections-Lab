# 來源與競賽前後成果政策

生效：2026-10-26；適用研究、文件、依賴、資料、SDK、AI 協作與未來產品程式。依使用者指示保留既有成果，不執行破壞性 Git 操作；本次不代替使用者報名、接受法律條款或提交。

## 分類與證據

每項成果在來源紀錄中至少區分：

| 類別 | 意義 | 必填證據 |
|---|---|---|
| `PREEXISTING` | 本次工作前即存在的使用者／第三方成果 | 原始位置、作者、建立時間或可驗 commit；無證據寫 UNKNOWN，不補造時間。 |
| `RESEARCH_PREPARATION` | 文獻索引、原創摘要、架構、環境與授權研究 | 查核時間、來源、主張／限制、作者或 agent。 |
| `ISOLATED_SPIKE` | SDK、依賴、幾何數學、物理／音訊 API 的隔離驗證 | 路徑、重現指令、依賴版本、原始 stdout／結果與結果日期；與正式功能分開。 |
| `EVENT_IMPLEMENTATION` | 已確認有效競賽時間與規則後建立的產品功能 | 實際開始 UTC、commit／diff、作者、使用的賽前成果與變更範圍。未確認前不得套此標籤。 |
| `THIRD_PARTY` | 軟體、binary、研究資料、音效、模型、貼圖 | 官方來源、license／條款、版本、SHA-256、修改與 attribution。 |
| `AI_ASSISTED` | Codex／Muse Code／其他模型產生或協助的內容 | 工具／模型（可知時）、日期、工作範圍、人工／程式驗證、來源依賴；不必保存機密 prompt。 |

AI 輔助是可與其他類別並列的標記，不能當作權利來源或真實性證明。無法確認模型版本、時間或作者時寫 `UNKNOWN`。文件存在不代表功能已運作；`IMPLEMENTED / PARTIAL / PLANNED / UNVERIFIED / FAILED` 與研究證據狀態分開。

## 本次工程邊界

依 [官方規則查核](HACKATHON_RULES.md)，尚未證實賽前自有產品程式、既有程式重用及非 Meta coding agents 的特別競賽規則。依使用者 Phase B，繼續完成研究、文件、依賴／SDK 準備、工程環境、測試基礎、數學驗證與隔離 technical spike；不大量實作正式產品功能。

官方公布 10/26 開始，但精確 kickoff／有效開發起算時間仍有 ET／EST 標示差異。不得把所有台北 10/26 工作自動歸為賽中作品。記錄真實 UTC，待取得明確規則再標記，不改寫歷史。隔離成果若未來重用，必須揭露其實際完成時間及重用範圍。

## 原始碼與資料管理

1. 原有成果以原始 commit、檔案 hash、實際盤點與差異保存；不變造作者／時間，不宣稱本次重新建立的檔案為過往原型。
2. 下載只進可重現 cache 或隔離 `third_party`；大型 SDK、binary、私有權重、整篇付費論文與音效庫不放 Git。記 URL、版本、digest 與重建方式。
3. 套件 lockfile、原創 fixture、必要 license／notice 可入庫；有不明授權的資料只放來源連結與待查記錄，不能藉轉格式移除原限制。
4. 每次資料轉換記原檔 hash、轉換程式／參數、輸出 hash、取樣率／單位／座標／頻帶；量測、推導、聽覺調校與 synthetic 值分開。
5. 存取失敗記 HTTP／工具狀態與取得範圍；搜尋摘要標 `SEARCH_ONLY`，不得稱已完整讀原文。無法執行的驗證寫 `NOT RUN` 及原因。
6. 不保存 API keys、登入 token、私人郵件、完整帳戶資料或具識別性的 prompt；原始測試輸出亦需去除 secrets。

## AI、科學與展示誠信

模型可建議參數與操作；物理／聲學數值須由可追溯的 solver 或量測產生。每個數值結果連到輸入、模型、版本、seed、時間與假設；不得將模型描述當成實測。不可將 SDK 有反射輸出推為已提供逐條幾何路徑，也不能將通過 smoke test 宣稱完成正式產品。

展示文件揭露重用的開源、SDK、資料、賽前準備、AI 協作與 mock／近似；只聲稱已執行並有紀錄的測試。人工或 agent 對結果的檢查不取代原作者授權。

## 正式開發與提交留痕

在確認入選及正式規則後建立一份不可含秘密的「開賽基線」：當時 UTC、目前 commit（沒有 Git 則註明）、既有檔案清單與 hash、已完成 spike／研究、採用資產及尚未確認項。未來以實際 diff／commit 說明賽中增量；不能重新標日期消除賽前成果。

提交前核對 [授權登錄表](LICENSE_REGISTER.md)、官方實際表單與公開內容。HC-02 要求的權利保證及授予主辦的廣泛授權，需與每項資產的可授權範圍相容；有疑義則移除／替換素材或取得明確許可。來源記錄不是自動取得額外權利的工具。

此政策可直接執行於研究與驗證；個人資格、報名入選與法律條款接受由使用者處理。本次未查閱帳戶狀態，不推測使用者已報名。
