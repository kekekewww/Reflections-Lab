# Parameter reference

This page describes every adjustable parameter in the Reflection Lab interface: its unit, range, default, effect, and when it takes effect. It is the complete version of the explanatory text on the main page; the interface keeps only field labels, values, status and warnings, and the detailed explanations live in hover tooltips and on this page.

2026-11-02 update: values have been checked against formal code and schemas, including Motion, short audio Render, Zones, Agent workflow, and Diagnostics. Defaults mean new drafts/initial settings; saved values apply when an existing project is loaded. This is a parameter and state contract, not a measurement or a claim that every value combination passed. See the [core handoff](../14-core-pipeline/CLAUDE_CODE_HANDOFF_20261102.md) for bounded actual DOM evidence, original failures, and correction receipts. The user has confirmed basic functionality; validation of the added scope is recorded separately.

<!-- english-original-anchor --> <a id="閱讀方式"></a>
## How to read this page

- **Units**: SI throughout (m, kg, s, rad, Hz). Angle fields take degrees (deg) and are converted internally to a quaternion `[x,y,z,w]`. Monitor gain is a digital gain in dB; **dBFS is not dB SPL**.
- **How changes apply**:
  - **Scene command**: checks the revision, applies atomically, rebuilds the physics world and re-solves acoustics; can be undone.
  - **Behaviour command**: stored as a draft first; Apply validates and commits it; can be undone.
  - **Immediate**: takes effect at once and does not enter the undo history.
- **When you can edit**: most Inspector and Scene list fields are editable only while the simulation is Ready or Paused and no replay is running; while running, the Inspector shows "Simulation is running; pause to edit structural settings".
- **Evidence labels**: materials are labelled Measured / Derived / Tuned / Synthetic; acoustic models are labelled analytical / numerical approximation / perceptual approximation. All materials in this project are currently Synthetic (hand-set example coefficients); geometric acoustics is a numerical approximation, and HRTF and late reverb are perceptual approximations.

## 1. Shared number-field rules

| Field type | Behaviour |
| --- | --- |
| Inspector number fields (position, dimensions, rotation, mass, temperature, reverb and so on) | Typing only edits a draft; Enter or leaving the field commits it. Esc restores the committed value. Empty, non-numeric or out-of-range values are not committed, and the field shows "Enter a finite number{bounds}". Nothing is committed while an input method is composing or when switching language. |
| Rule number fields (volume, pitch, cooldown) | Every keystroke goes into the rule draft; Apply commits it. Out-of-range values show "Enter a finite number from {min} to {max}. Your draft is retained." Esc restores the value from when the field gained focus. |
| Mapping editor number fields | A draft string; out-of-range values are only flagged, and the error list appears at the bottom of the mapping editor. |

## 2. Object Inspector

Shown when an object is selected.

### 2.1 Identity and actions

| Parameter | Effect and when it applies | Notes |
| --- | --- | --- |

### 2.2 Transform (authored initial pose)

| Parameter | Unit | Range / step | Default | Effect and when it applies |
| --- | --- | --- | --- | --- |
| Position X / Y / Z | m | −200 to 200, step 0.1 | New objects `[0, 2, 0]` | Scene command. Sets the initial pose; the live position while running comes from physics. |
| Dimensions | m | 0.01 to 100, step 0.1 | Box and sphere `[0.5, 0.5, 0.5]`; capsule `[0.5, 1, 0.5]` | Scene command. A box has X / Y / Z fields that change both the collider and the acoustic faces; a sphere has a single Diameter field that changes all three axes together; a capsule has Diameter (X = Z) and Height (Y), and the height must not be less than the diameter; otherwise the field keeps your input and shows the reason. |
| Rotation X / Y / Z | deg (XYZ Euler) | −360 to 360, step 1 | No rotation | Scene command; converted to a unit quaternion. |

When scaling with the transform tool in the 3D view, the minimum size is 0.05 m; spheres scale uniformly and capsule width and depth stay linked.

### 2.3 Rigid body physics

| Parameter | Unit | Range / options | Default | Effect and when it applies |
| --- | --- | --- | --- | --- |
| Body mode | — | Dynamic · gravity enabled; Dynamic · no gravity; Fixed · immovable; Kinematic · prescribed motion | New objects Dynamic · gravity enabled; in the default scene the walls, floor and speaker are Fixed and the ball is Dynamic · gravity enabled | Scene command. Switching between the two Dynamic modes updates in place; other changes rebuild the physics world. No gravity is still a dynamic body that collides and can be pushed; Fixed is not affected by forces. Kinematic can be driven at fixed steps by Motion Move To, Move & Release, or a valid trajectory. Impulse accepts Dynamic only; Kinematic release requires explicitly choosing zero or transferred velocity, and the acceleration parameter applies only to Dynamic. |
| Mass | kg | 0.001 to 10000, step 0.1 | New objects 1 kg; default ball 1 kg, fixed boxes 100 kg | Scene command. Disabled for Fixed. First person can only grab dynamic bodies of 0.1 to 20 kg. |
| Friction coefficient | unitless | 0 to 2, step 0.05 | New objects 0.5; boxes 0.6, ball 0.4 | Scene command; collider friction using the Rapier default combine rule (inferred; Tuned / Synthetic). |
| Restitution coefficient | unitless | 0 to 1, step 0.05 | New objects 0.4; boxes 0.15, ball 0.55 | Scene command; collision bounciness (Tuned / Synthetic). |
| Speed | m/s | Read-only | — | Shown when velocity data exists. |

<!-- english-original-anchor --> <a id="24-聲學材質"></a>
### 2.4 Acoustic material

| Parameter | Options | Default | Effect and when it applies |
| --- | --- | --- | --- |
| Surface material | Hard surface, Absorptive surface, Wood example, Metal example (all Synthetic) | New objects wood; in the default scene walls are hard, the floor is wood, the ball is metal and the speaker is absorptive | Scene command, then an acoustic re-solve. Each material has 7 bands from 125 to 8000 Hz; absorption + reflection + transmission = 1, transmission is 0 and scattering 0.1. The coefficients are hand-set examples, not measurements. |
| Acoustic role | Exclude; Static reflecting surface; Dynamic occluder; Dynamic reflector (subject to backend support) | New objects Dynamic occluder; walls and floor Static reflecting surface; ball Dynamic occluder; speaker Exclude | Scene command, then a re-solve. Exclude is left out; only Fixed + Static reflecting surface performs static reflection, while the same role on non-Fixed bodies still only occludes. Dynamic occluder only occludes. Dynamic reflector performs first-order reflection and occlusion from the actual current pose instead of falling back to occlusion alone. |

Boxes, spheres, and capsules can all edit the four materials and four roles above. Spheres/capsules use analytical closed-volume occlusion and bounded numerical specular positions. All three shapes share the geometry budget. Curved-surface focusing/caustics/curvature divergence, retarded time, and moving-boundary Doppler are not provided; see the [bounded model contract](../15-ui-parameter-audit/acoustic-geometry/MODEL_CONTRACT.md).

## 3. Listener / environment

Open it with "Listener / environment" in the Scene list.

| Parameter | Unit | Range / options | Default | Effect and when it applies |
| --- | --- | --- | --- | --- |
| Receiver position | m | −200 to 200, step 0.1 | `[0, 1.6, 4]` | Scene command; the Listener becomes "Independent". In first person the Listener follows the head and the fields are disabled. |
| Receiver orientation | deg (XYZ) | −360 to 360, step 1 | No rotation | Same as above. |
| Propagation medium | — | Air; Vacuum · no airborne propagation | Air | Immediate: clears scheduled sound, starts a new run epoch and re-solves; not undoable. In vacuum there is no airborne propagation, and the path area explains this instead of showing 0; mechanical collisions remain. |
| Air temperature | °C | −80 to 100, step 1 | 20 °C | Immediate; also sets the medium to air. Speed of sound c = √(1.4 × 287.05 × (273.15 + T)) (ideal gas, analytical). Disabled in vacuum. |
| Speed of sound | m/s | Read-only | 343 m/s at 20 °C | Shows "Not provided" in vacuum. |
| Backend / model | Read-only | — | Custom Web Geometric Core; Numerical approximation · first-order finite surfaces / zero-phase magnitude | — |

Gravity (`[0, −9.81, 0]` m/s²) and band air absorption (currently all 0, Synthetic) have no interface fields.

Environment settings persist with project save/load and JSON import/export, including the medium, temperature and explicit atmospheric-acoustic parameters. Loading an old project without an environment field restores the original Air/20 °C/343 m/s defaults rather than retaining hidden settings from the previous project. Environment changes still do not enter the ordinary scene undo history.

## 4. Sound behaviours

In the Sound behaviors section of the object Inspector. Edits are stored as drafts and kept when you change the selection; Apply checks the revision and commits them, and they can be undone.

<!-- english-original-anchor --> <a id="41-分類與新增規則"></a>
### 4.1 Classification and new rules

| Parameter | Options | Default | Effect |
| --- | --- | --- | --- |
| Classification | Creative; Physical-inspired; Hybrid; Procedural | From the profile; Creative when there is none | Records design intent only and does not change synthesis; when the profile has no rules it adds one continuous (AlwaysOn) rule. |
| Trigger for a new rule | 19 triggers; availability depends on trusted producers and a valid Zone registry | OnImpact | New-rule defaults: sine oscillator at 440 Hz, volume about 0.063 (−24 dBFS), pitch 0, fade-in 0.01 s, fade-out 0.06 s; discrete triggers use cooldown 0.08 s, a voice limit of 4 and a one-shot length of 0.22 s; continuous triggers use cooldown 0 and a limit of 1. |

<!-- english-original-anchor --> <a id="42-規則卡"></a>
### 4.2 Rule card

| Parameter | Unit | Range / step | Default | Effect |
| --- | --- | --- | --- | --- |
| Enabled | — | On / off | On | Enables the rule; for a scene source it also syncs the playing state. Cannot be ticked when the object binding is disabled. |
| Trigger | — | 19 options under the shared capability contract | Per rule | OnBounce is a Tuned separation subset for unmoved Fixed supports. OnEnterZone/OnExitZone require an explicit valid zoneId and a real producer; missing prerequisites show a reason and prevent Apply. |
| Trigger zone | — | Registered zone ID | Select a zone first for new rules; retain existing values | Shown only for Zone triggers. New choices allow enabled zones only; existing disabled references remain visible. A missing ID does not silently select the first zone; see section 18. |
| Sound asset | — | Procedural sound · Oscillator, or any imported asset that is ready | Procedural sound | Switching back to the oscillator resets it to a 440 Hz sine; with an asset, continuous triggers loop it. |
| Volume | linear gain | 0 to 4, step 0.05 | About 0.063 | Rule volume. |
| Pitch | semitones | −24 to 24, step 1 | 0 | Playback pitch offset. |
| Cooldown | s | 0 to 10, step 0.05 | Discrete 0.08 s; continuous 0 | Minimum interval between two triggers of the same rule. |
| Apply / Discard | — | — | — | Apply is disabled when a field is invalid, the draft is stale, a mapping has an error, nothing changed, or an unsupported trigger is enabled. |
| Delete rule | — | — | — | Disabled while a draft exists; deleting the last rule also removes the object binding and profile. |
| Preview scene acoustics | — | — | — | Previews this rule in the current static scene through the full acoustic chain; needs a paused simulation and no replay. Impact rules first need an admitted impact event selected in "Events & recording"; drafts must be applied first. |

Rule priority (0 to 100), voice limit (1 to 16), fades (0 to 5 s), one-shot length (0.005 to 30 s), conditions, emitter position, and oscillator frequency and waveform have no interface fields; they can only be set in the project file.

<!-- english-original-anchor --> <a id="43-參數映射"></a>
### 4.3 Parameter mappings

Map a physical quantity to a sound parameter. Each rule can have up to 8 mappings and only one per output parameter (so 3 in practice).

| Parameter | Unit | Range / options | New-mapping default | Notes |
| --- | --- | --- | --- | --- |
| Input metric | Per metric | Source speed m/s, angular speed rad/s, normal impulse N·s, closing speed m/s, tangent speed m/s, slip speed m/s, contact support force N | Source speed (the default impact mapping uses closing speed) | Trigger and metric compatibility is checked on Apply. |
| Output parameter | Per parameter | Gain (linear), pitch (semitones), filter cutoff frequency (Hz) | The first unused one | Outputs already in use are disabled. |
| Input minimum / maximum | Input unit | 0 to 1e9; the minimum must be below the maximum | 0 / 10 | — |
| Output minimum / maximum | Output unit | Gain 0 to 4, pitch −24 to 24, cutoff 20 to 20000 Hz; minimum not above maximum | Gain 0 / 1; pitch 0 / 12; cutoff 20 / 20000 (default impact mapping 0.025 / 0.25) | Values outside the parameter range cannot be applied. |
| Interpolation | — | Linear; Step | Linear | — |
| Parameter smoothing | s | 0 to 1, step 0.01 | 0.02 s (default impact mapping 0.015 s) | Smooths the sound parameter only; it does not change physics or propagation timing. |
| Clamp | — | Always on | On | Cannot be turned off. |
| Curve points x / y | normalized 0 to 1 | 2 to 16 points; first x = 0, last x = 1, x strictly increasing | `(0,0)`, `(1,1)` | A new point goes into the middle of the widest gap; the first and last points, and points at the minimum count, cannot be removed. The curve is an authored control curve, not an acoustic measurement. |

### 4.5 Drafts and preview

## 5. Monitor

At the bottom of the page. Everything applies immediately, can be changed while running, and does not enter the undo history.

| Parameter | Unit | Range / options | Default | Effect |
| --- | --- | --- | --- | --- |
| Enable listening / Mute monitor | — | Toggle | Not enabled | The first press creates the audio context and unmutes; later presses toggle mute. Mute only affects monitoring and does not pause physics. Enabling listening does not start the simulation. |
| Audio buffer | — | Low latency; Balanced; Stable | Stable | Like a DAW buffer size: a larger buffer is less likely to drop out but delays sound more. Changing it safely restarts the audio engine (fade out, rebuild, restore monitor gain, mute, routing and reverb settings, then re-admit continuous sources); the choice is stored in this browser. It is refused with a reason during recording, replay or a pending placement. |
| Scheduling lookahead | ms | Read-only; Low latency 60, Balanced 80, Stable 120 | — | Sound onsets such as impacts are scheduled this far ahead, so a brief main-thread stall does not make them late. It applies to onsets only and does not change how propagation delay is computed (emission time and propagation delay are each counted once). |
| Device output latency | ms | Read-only | — | baseLatency + outputLatency as reported by the browser. |
| Output underruns | count | Read-only | — | Output buffer underruns reported by the browser (like a DAW xrun counter); shows NOT_AVAILABLE, not 0, when the browser does not provide it. |
| Monitor gain | dB (digital) | −40 to +12, step 1 | 0 dB | The selected preference is saved even before listening is enabled and is applied when the audio engine is created; changing it does not itself unmute the default mute state. Adjusts monitor gain. The master output keeps a fixed −6 dB headroom and a −3 dBFS limiter. dBFS is not dB SPL; actual loudness depends on the system and speaker volume. |
| Monitor routing | — | Simulated; Raw reference | Simulated; the choice can be saved before enabling audio | Simulated goes through propagation, HRTF and reverb; Raw reference is a centred dry signal without propagation or HRTF that also bypasses reverb. Different levels between them are not an error. |
| Synthetic late reverb | — | On / off | Off | Synthetic late reverb (perceptual approximation); toggling it stops a running preview. |
| Synthetic decay time | s | 0.1 to 4, step 0.1 | 1.2 s | Time for a seeded noise IR to decay exponentially to −60 dB; not a measured RT60. |
| Reverb wet gain | linear | 0 to 1, step 0.01 | 0.12 | Share of the wet reverb signal. |
| Voices | Read-only | — | — | Current voices / limit (the limit shows 16 before audio is enabled). |

<!-- english-original-anchor --> <a id="6-運算控制"></a>
## 6. Simulation controls

| Control | Effect |
| --- | --- |
| Start simulation / Pause / Resume simulation | Starts or pauses the physics simulation; disabled on error or during replay. In first person the interaction controls resume it. |
| Reset | Interrupts any recording, rebuilds the physics world from the current scene revision and re-solves; it is not an undo and keeps sealed recordings. |
| Undo / Redo | Command history of the scene and sound behaviours; it does not reverse simulation time. |

The physics fixed step is 1/60 s and cannot be changed; the view interpolates between steps.

### 11.2 First person

Starts after "Enter first person" and a successful mouse lock. The click that acquires the lock never grabs, throws or places.

| Input | Context | Effect |
| --- | --- | --- |
| W / A / S / D | Running | Move; walking speed 2 m/s. |
| Shift | Same | Sprint at 3.5 m/s. |
| Mouse move | Mouse locked | Look; sensitivity 0.002 rad per unit, pitch limited to about ±87°. Not adjustable. |
| Left button | Not holding | Grabs the first grabbable dynamic body (0.1 to 20 kg) within 3 m of the crosshair. |
| Left button | Holding | Throws (fixed impulse 6 N·s). |
| Left button | During a right-button preview | Cancels the preview without placing. |
| Hold right button | Not holding | Shows a placement preview: it attaches to a surface the crosshair hits within the preview distance, otherwise it floats in mid-air; releasing the right button places. A quick click also places. |
| Right button | Holding | Puts the object down (ends the grab and keeps the current velocity). |
| Wheel | Holding or previewing | Adjusts the distance, about 0.75 to 3 m depending on object size; default 2 m. |
| R | Hold while holding; toggle while previewing | While holding, rotates the object with the mouse; while previewing, toggles rotate mode so moving the mouse sideways rotates the preview in 15° steps. |
| F | With a clear target | Freezes or unfreezes. |
| G | Holding | Gentle place: finds a support point and lowers the object slowly; does nothing without support. |
| E | Optional | Grabs or puts down (same as the left and right buttons). |
| B | Optional | Cancels the placement preview. |
| L | Running | Pauses and opens the object library to choose the placement shape, releasing the mouse. |
| Enter | First person | Pauses or resumes. |
| Esc | First person | Cancels the preview if there is one; otherwise releases the mouse and pauses safely. |
| Tab | First person | Returns focus to the interface and pauses. |
| Arrow keys | Alternative input with the view focused | Look in steps. |

Placement rules: each release of the right button creates at most one object, and it can be undone. Objects placed in mid-air default to Dynamic · no gravity (they stay in the air but still collide); surface placements keep the default Dynamic · gravity enabled. The position must be within 3.5 m and must not overlap other bodies or the player. After a successful placement the simulation keeps its previous running state.

Alternative input: after "Enable no-lock controls", the buttons below the view grab, put down, throw, start a placement preview, place and cancel the preview; each press of a movement button walks for 200 ms.

## 14. Fixed values (not adjustable)

| Item | Value |
| --- | --- |
| Physics fixed step | 1/60 s |

## 15. Current limitations and known issues

- Dynamic reflection computes first-order specular reflection using actual snapshot position/orientation, without moving-boundary retarded-time/Doppler solving. Non-Fixed Static reflecting surface still only occludes; Dynamic reflector must be explicitly selected for reflection.
- First person can only grab bodies of 0.1 to 20 kg; otherwise it shows "The first object hit is fixed, controlled or over the grab budget".
- The transform tool minimum size is 0.05 m, while the Inspector field allows 0.01 m.
- Object name, physics material, rule priority, voice limit, fades and oscillator frequency have no interface fields.
- In the editor, right-dragging also orbits the camera.
- These are tiered capacity and rejection boundaries, not real-time performance guarantees. WAV import permits at most 8 MiB, 2 channels, and 120 seconds; the decoded bank permits at most 64 MiB/64 assets. Recorder permits at most 18000 frames, 64 MiB trace, 256 objects, 100000 unique events, and 2048 events per frame; exhaustion retains an Interrupted prefix. Target-device long-duration performance and the original 600-second gate remain separate.

## 17. Audio export (Render)

This panel uses original sound decisions, paths, and pinned assets from a complete recording, through the real `OfflineAudioContext` / existing `AudioEngine`, to produce short float32 WAV excerpts. `busy` means preparing/running the 3-second capture or generating audio files.

| Control / parameter | Unit, range / initial value | Effect and state restrictions |
| --- | --- | --- |
| Explanatory help | Open / close help | Explains short recordings, Wet, and pre-master stem semantics. |
| Record 3 seconds | Fixed 3 s; no duration field | Shown only when production provides a capture port; disabled while busy; uses the same world, Motion hooks, and recorder. |
| Preserve tail | s; 0 to 10; step 0.5; default 2 | Disabled while busy. Enter/blur commits valid values only; blank, non-finite, or out-of-range drafts disable Generate audio files and show a reason. Esc restores the committed value. Appends after the emission interval and does not reconstruct unknown earlier history. |
| Per-source stems | Checked / unchecked; checked by default | Disabled while busy; selects recorded sound emissions grouped by original authored object. Unchecking still outputs mix, master, and dry. |
| Generate audio files | Button | Disabled while busy, when the tail draft is invalid, or without a complete `captured` recording with frameCount>0. An invalid draft does not silently reuse the previous committed tail value to start a new job; generation is available only after correcting it or restoring it with Esc. Each run creates a new job with fixed sources and configuration. |
| Cancel | Button | Shown only during `rendering`; permits cancelling preparation or a job not yet atomically published. Cancellation/failure does not expose partial new audio files; the previous completed output can remain downloadable. |
| Propagated mix (Wet), Master output, Original content (Dry), stems | Per-file download buttons; read-only size | Appear only after the complete job is published. Names are generated automatically; no rename field. Output is stereo float32 PCM WAV at the recording's sample rate (44.1 or 48 kHz); the panel has no sample-rate/bit-depth selector. |
| Download provenance and hash manifest | JSON manifest download | Shown only with published audio files; includes job, configuration, results, each file's SHA-256, control observations, and semantics. |
| Status, progress, errors, boundary limitations | Read-only | Recording / completed count / downloadable; progress appears only while rendering. “Boundary limitations” appears only for `tailTruncated` or `historyIncomplete`; these are not adjustable parameters. |

Each short-excerpt job has an emission interval of at most 30 s; the context, including pre-roll, emissions, and tail, is at most 45 s. There are at most 16 outputs (3 standard files plus at most 13 object stems). Estimated working memory is limited to 256 MiB and encoded output to 192 MiB; all budgets must be satisfied together, so this does not guarantee 16 files of arbitrary duration. Excessive stems are explicitly rejected; disable stems and generate again. These are backend validation boundaries, not editable panel budgets. The UI's Record 3 seconds does not provide an arbitrary 30-second duration field.

Wet is direct sound + early reflections + configured Synthetic tail, before master; Dry is content before propagation/spatialization/master; Master applies the configured headroom, monitor, limiter, and safety graph. With identical sources, time, configuration, and seed, pre-master stems sum to Wet within floating-point error; individually processed nonlinear-master stems need not sum. Native HRTF coefficient identity is `browserManagedUnspecified`. This panel has no custom HRTF, listener replacement, separate late tap, time-window, chunks, normalize, master-setting, or output-format controls, and makes no claim of long-recording/ADM or unbounded rendering.

## 18. Zones

A zone is an independent static event region, not a rigid body, collider, or acoustic surface. The panel stores at most 16 zones, counting enabled and disabled zones. Creation/editing is allowed only while simulation is paused, without recording/replay, and in the editor. Defaults below apply to a new draft; editing an existing zone reads its existing values.

| Control | Unit / range | New-zone default | Effect, state, and restrictions |
| --- | --- | --- | --- |
| Add zone | At most 16 | No draft created | Opens an unsaved draft; disabled if a draft exists, a commit is pending, or the limit is reached. |
| Zone ID | 1–64 characters; `^[a-z][a-z0-9._-]{0,63}$`; must not duplicate an existing ID | Lowest unused `zone.1`, `zone.2`… | Editable only during creation; existing IDs are read-only and editing cannot rename them. |
| Name | 1–80 characters, not all whitespace | Traditional Chinese `新區域` / English “New zone” | Saving trims leading/trailing whitespace; the display name does not replace the stable ID. |
| Shape | Axis-aligned box `aabb` / sphere `sphere` | `aabb` | Boxes have no rotation; after switching shape, only the dimensions of the current shape are saved. |
| Enabled (draft) | Boolean | `true` | Committed together with Save zone; disabling stops enter/exit detection without deleting the zone or references. |
| Center position X / Y / Z | m; −200–200 on each axis; `step="any"` | `[0, 1, 0]` | Must be finite; world coordinates, +Y up. |
| Half-extents X / Y / Z | m; 0.05–50 on each axis; `step="any"` | `[1, 1, 1]` | Boxes only; each full side length is twice its half-extent. |
| Radius | m; 0.05–50; `step="any"` | `1` | Spheres only. |
| Boundary hysteresis | m; 0–0.25 and strictly below the smallest half-extent/radius; `step="any"` | `0.02` | Entry uses an inset boundary, exit an outset boundary; does not change the displayed wireframe size. |
| Save zone | Action / form submit | — | Commits atomically when valid and current; disabled if invalid, stale, committing, or the editing state disallows it. Success requires a newer scene revision and matching zone contents; otherwise the draft is retained and an error appears. |
| Cancel draft / Esc | Action | — | Discards uncommitted values; disabled during commit. Esc during IME composition does not cancel. |
| Enable / disable in list | Boolean, immediate commit | Existing value | Can submit a toggle directly when no draft exists; still subject to paused/editor, revision, and registry guards. |
| Edit / delete | Per-zone actions | — | Disabled with any draft or pending commit. Deletion first checks all rules: a trigger or emitter attachment referencing the zone returns `ZONE_IN_USE`, lists `profileId/ruleId`, and requires changing/removing the reference first. |
| Global Undo / Redo | Shared scene actions | — | Successful creation, update, enable/disable, and deletion enter the shared scene history; the zone panel has no separate Undo buttons. |

A draft retains the project identity, scene revision, and zone registry pin from its creation. Even if input fields remain editable, changes to Scene or the zone list prevent saving; cancel and edit again. Invalid input retains the original string and displays a validation message instead of silently restoring the old value. Zone data persists through formal Scene/Project save/import; the panel has no separate zone Import/Export buttons.

`OnEnterZone` / `OnExitZone` rules require an explicit `zoneId`. New rules list only enabled zones. Existing rules continue showing their original disabled references, so disabled must not be mistaken for deleted. Sound remains object-attached by default; the zone-center anchor is used only when zone attachment is explicitly selected, and an existing center anchor for a disabled zone remains valid.

The event model is labelled **Derived**: it samples valid object centers after each authoritative fixed step completes, not whole-collider overlap or continuous sweeps. For nominal boundary distance `d` and hysteresis `h`, an outside object enters at `d ≤ −h` and an inside object exits at `d > +h`. The first step after start/reset, rebuild, zone changes, or a position discontinuity only establishes a baseline and does not fabricate enter/exit events. Position-continuous mode changes or Motion release do not erase real crossings merely because mode changed. A fast crossing within one step can produce no event when both endpoint samples are outside. At most 16 zones × 256 poses; the per-step total of existing plus new events is limited to 2048, with explicit rejection on excess. This is not a performance promise.

Editor wireframes show the **nominal region** only and are hidden in FPS or replay. Enabled/disabled zones use different colors/opacity. Wireframes have no picking/collision/acoustic effect and do not block selection of objects behind them. The sphere wireframe's 24×16 display segments do not approximate the producer's event boundary: the producer uses analytical distance.

This panel reads JavaScript control-thread costs and browser native output counters. Only one parameter changes observation state. Diagnostics do not exist before listening is enabled, and values show `—`; that does not mean a zero measurement.

|---|---|---|
| Enable cost observations | Checkbox `false/true`; unchecked and disabled before audio exists; AudioEngine diagnostics default to `true` when created | Operable only after listening is enabled. Re-enabling resumes sampling and restarts the native output delta window, without treating the gap as zero. |
| Update costs and component counts | Details/summary; initially collapsed | Expands/collapses 11 read-only detail rows; no numeric input. |
| Control-thread observation explanation | Focusable label + HelpTip | Explains scope and p95; does not change measurements. |

| Observation disabled; retained data shown | Read-only status text, only when enabled=false | Old data remains readable; does not imply new samples were collected. |
