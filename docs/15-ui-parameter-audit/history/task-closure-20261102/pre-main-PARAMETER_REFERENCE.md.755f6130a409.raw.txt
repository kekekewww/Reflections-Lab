# 參數設定參考

本頁逐項說明 Reflection Lab 介面上每個可調整的參數：單位、範圍、預設值、作用，以及何時生效。主頁面的說明文字以此為完整版本；介面上只保留欄位名稱、數值、狀態與警告，詳細解說改由懸浮提示與本頁提供。

2026-11-02 更新：數值依正式程式與 schema 核對，包含 Motion、短音訊 Render、Zones、Agent workflow 與 Diagnostics。預設指新建草稿／初始設定；載入既有專案時以保存值為準。這是參數與狀態契約，不是量測或所有數值組合均通過的宣告；有限實際 DOM、原失敗與修復收據見[核心交接](../14-core-pipeline/CLAUDE_CODE_HANDOFF_20261102.md)。基本功能已有使用者確認，新增範圍的驗證分開記錄。

## 閱讀方式

- **單位**：一律 SI（m、kg、s、rad、Hz）；角度欄位以度（deg）輸入，內部轉成 quaternion `[x,y,z,w]`。監聽音量是數位增益 dB，**dBFS 不等於 dB SPL**。
- **生效方式**：
  - **場景命令**：驗證 revision 後原子套用，重建物理世界並重新求解聲學，可復原。
  - **行為命令**：先存成草稿，按「套用」後驗證並提交，可復原。
  - **即時**：立刻生效，不進入復原紀錄。
- **編輯條件**：多數 Inspector 與場景清單欄位只在模擬「準備就緒」或「已暫停」、且不在重播時可編輯；運算中會顯示「暫停後才能編輯結構設定」。
- **證據標示**：材質標 Measured／Derived／Tuned／Synthetic；聲學模型標 analytical／numerical approximation／perceptual approximation。本專案目前所有材質都是 Synthetic（手工示範係數），幾何聲學是數值近似，HRTF 與尾響是感知近似。

## 1. 數字欄位的共同規則

| 欄位類型 | 行為 |
| --- | --- |
| Inspector 數字欄（位置、尺寸、旋轉、質量、溫度、尾響等） | 打字時只是草稿；按 Enter 或離開欄位才提交。Esc 還原為已提交的值。空白、非數字或超出範圍的值不會提交，欄位會顯示「請輸入{範圍}的有限數值」。輸入法組字中與切換語言時不提交。 |
| 規則數字欄（音量、音高、冷卻時間） | 每次輸入都寫進規則草稿，按「套用」才提交；超出範圍顯示「請輸入 {min} 至 {max} 的有限數值；原草稿保留」。Esc 還原為聚焦時的值。 |
| 映射編輯器數字欄 | 草稿字串；超出範圍只標示錯誤，錯誤清單列在映射編輯器底部。 |

### 2.4 聲學材質

| 參數 | 選項 | 預設 | 作用與生效 |
| --- | --- | --- | --- |
| 表面材質 | 硬質表面、吸音表面、木質示範、金屬示範（皆 Synthetic） | 新物件木質；預設場景牆為硬質、地板木質、球金屬、喇叭吸音 | 場景命令後重新求解聲學。每種材質有 125～8000 Hz 共 7 個頻帶，吸收＋反射＋穿透＝1，穿透為 0，散射 0.1。係數是手工示範值，不是量測值。 |
| 聲學角色 | 不參與幾何聲學；靜態反射表面；動態遮蔽物；動態反射面（依後端能力） | 新物件動態遮蔽物；牆與地板靜態反射表面；球動態遮蔽物；喇叭不參與 | 場景命令後重新求解。「不參與」排除；Fixed＋「靜態反射表面」才作靜態反射；非 Fixed 的該角色仍只遮擋。「動態遮蔽物」只遮擋；「動態反射面」依當次真 pose 作一階反射與遮擋，不再退成純遮擋。 |

方塊、球體與膠囊皆可編輯上述四種材質與四種角色，球／膠囊使用解析閉體遮擋及有界數值鏡射位置。三形狀共用幾何預算；曲面聚焦／caustics／curvature divergence、retarded-time／移動邊界 Doppler 未提供，詳見[有限模型契約](../15-ui-parameter-audit/acoustic-geometry/MODEL_CONTRACT.md)。

## 3. Listener／環境

在場景清單點「Listener / 環境」開啟。

| 參數 | 單位 | 範圍／選項 | 預設 | 作用與生效 |
| --- | --- | --- | --- | --- |
| 接收位置 | m | −200～200，步進 0.1 | `[0, 1.6, 4]` | 場景命令；Listener 設為「獨立位置」。進入第一人稱時 Listener 跟隨頭部，欄位停用。 |
| 接收方向 | deg（XYZ） | −360～360，步進 1 | 無旋轉 | 同上。 |
| 傳播介質 | — | Air · 空氣；Vacuum · 無空氣傳播 | Air | 即時：清空排程中的聲音、開新的運算紀元並重新求解；不進入復原紀錄。真空時沒有空氣聲傳播，路徑區顯示說明而不是 0；機械碰撞仍存在。 |
| 空氣溫度 | °C | −80～100，步進 1 | 20 °C | 即時；同時把介質設為空氣。聲速 c = √(1.4 × 287.05 × (273.15 + T))（理想氣體，analytical）。真空時停用。 |
| 聲速 | m/s | 唯讀 | 20 °C 時 343 m/s | 真空時顯示「未提供」。 |
| 後端／模型 | 唯讀 | — | Custom Web Geometric Core；Numerical approximation · 一階有限面／零相位幅度 | — |

重力（`[0, −9.81, 0]` m/s²）與頻帶空氣吸收（目前全為 0，Synthetic）沒有介面欄位。

環境設定會隨專案儲存、載入與 JSON 匯入／匯出保存，包括介質、溫度及明示的大氣聲學參數。舊專案未帶環境欄位時，載入會恢復原始空氣／20 °C／343 m/s 預設；不沿用前一個專案的隱藏設定。環境變更仍不進入一般場景復原紀錄。

## 4. 聲音行為

位於物件 Inspector 的 Sound Behaviors 區。編輯先存成草稿，換選取物件時保留；按「套用」後檢查 revision 並提交，可復原。

### 4.1 分類與新增規則

| 參數 | 選項 | 預設 | 作用 |
| --- | --- | --- | --- |
| 分類 | Creative · 創意；Physical-inspired · 材質啟發；Hybrid · 混合；Procedural · 程序音 | 依設定檔；沒有時為 Creative | 只記錄設計意圖，不改變合成方式；設定檔沒有規則時會加入一條持續播放（AlwaysOn）規則。 |
| 新增規則的觸發條件 | 19 種；依可信 producer 與有效 Zone registry 判定可用 | OnImpact | 新規則預設：正弦波 440 Hz、音量約 0.063（−24 dBFS）、音高 0、淡入 0.01 s、淡出 0.06 s；離散觸發冷卻 0.08 s、同時發聲上限 4、單次長度 0.22 s；持續觸發冷卻 0、上限 1。 |

## 5. 監聽（Monitor）

位於頁面底部。全部即時生效，運算中也可調整，不進入復原紀錄。

| 參數 | 單位 | 範圍／選項 | 預設 | 作用 |
| --- | --- | --- | --- | --- |
| 啟用聆聽／靜音監聽 | — | 開關 | 尚未啟用 | 第一次按下建立音訊環境並解除靜音；之後切換靜音。靜音只影響監聽，不暫停物理。啟用聆聽不會自動開始運算。 |
| 音訊緩衝 | — | 低延遲；平衡；穩定 | 穩定 | 像 DAW 的緩衝大小：緩衝越大越不易斷音，但聲音延遲越長。切換時安全重建音訊引擎（淡出、重建、恢復監聽音量、靜音、路由與尾響設定，再重新排入持續音源）；選擇存在此瀏覽器。錄製、重播或放置交易進行中會拒絕切換並說明原因。 |
| 排程餘裕 | ms | 唯讀；低延遲 60、平衡 80、穩定 120 | — | 撞擊等聲音的開始時間會預留這段時間，主執行緒短暫卡頓時聲音仍能準時開始。只用於聲音開始時間，不改變傳播延遲的計算（發聲時間與傳播延遲各只計一次）。 |
| 裝置輸出延遲 | ms | 唯讀 | — | 瀏覽器回報的 baseLatency + outputLatency。 |
| 輸出中斷 | 次 | 唯讀 | — | 瀏覽器回報的輸出緩衝不足次數（類似 DAW 的 xrun 計數）；瀏覽器不提供時顯示 NOT_AVAILABLE，不顯示 0。 |
| 監聽音量 | dB（數位） | −40～+12，步進 1 | 0 dB | 啟用聆聽前也保存所選偏好，建立音訊引擎後套用；調整本身不解除預設靜音。調整監聽增益。主輸出固定保留 −6 dB headroom，並有 −3 dBFS 限幅。dBFS 不等於 dB SPL；實際響度取決於系統與喇叭音量。 |
| 監聽路由 | — | Simulated；Raw 參考 | Simulated；啟用前可保存選擇 | Simulated 經過傳播、HRTF 與尾響；Raw 參考是置中、無傳播與 HRTF 的乾聲，也略過尾響。兩者音量不同不代表錯誤。 |

| 合成衰減時間 | s | 0.1～4，步進 0.1 | 1.2 s | 以固定種子的雜訊 IR 指數衰減到 −60 dB 的時間；不是量測的 RT60。 |

| 發聲數 | 唯讀 | — | — | 目前發聲數／上限（啟用前顯示上限 16）。 |

## 15. 目前限制與已知問題

- 動態反射依 snapshot 真位置／旋轉求一階鏡射，沒有移動邊界 retarded-time／Doppler 解；非 Fixed 的「靜態反射表面」仍只遮擋，須明選「動態反射面」才反射。
- 第一人稱只能抓取 0.1～20 kg 的物體；超出時顯示「第一個命中物件已固定、受控或超過抓取預算」。
- 變形工具的最小尺寸是 0.05 m，Inspector 欄位允許 0.01 m。
- 物件名稱、物理材質、規則優先序、同時發聲上限、淡入淡出與振盪器頻率沒有介面欄位。
- 編輯器中右鍵拖曳也會環繞相機。
- 上述為分層容量與拒絕界線，不是即時效能保證。WAV 匯入最多8 MiB、2聲道、120秒，decoded bank 最多64 MiB／64 assets。Recorder 最多18000 frames、64 MiB trace、256物件、100000唯一事件、每frame2048事件；耗盡保留 Interrupted 前綴。目標裝置長時效能及原600秒 gate仍另列。

## 16. 動作（Motion）

Motion 使用目前選取物件的既有剛體模式；此面板沒有另外的「動態／運動學」切換欄。表單在模擬運行、錄製、重播或已有動作執行時停用編輯。數值欄以 Enter 或一般離焦提交有限且在範圍內的值；Escape 還原已提交值，Enter 不會代替按下儲存。

| 控制／參數 | 單位、範圍／選項 | 初始值 | 作用與狀態限制 |
| --- | --- | --- | --- |
| 選取物件 | 唯讀物件 ID | 目前選取物件；未選取時顯示提示 | 使用 Scene 同次發布的 Motion 快照；不是物件選單。 |
| 動作 ID | 必填；`[a-z][a-z0-9._-]{0,63}`，最多64字元 | 選取後為 `motion.<objectId>`（截至64字元） | 同 ID 儲存更新既有動作；無選取物件時停用。 |
| 動作種類 | `moveTo` 移動到／`moveAndRelease` 移動並釋放／`impulse` 施加衝量 | `moveTo` | 面板沒有 `trajectory` 選項。 |
| 目標位置 X／Y／Z | m；各軸 −200～200；`step="any"` | 選取物件當前位置；尚未選取時 `[0,1,0]` | 只在移動類型顯示。 |
| 衝量 X／Y／Z | N·s；各軸 −1000～1000；`step="any"` | `[0,1,0]` | 只在 `impulse` 顯示；向量長度另須不超過「最大衝量」，不能只看各軸合法。執行要求 dynamic 剛體。 |
| 最大速度 | m/s；0.01～3；`step="any"` | 1 | 只在移動類型顯示。 |
| 動態控制最大加速度 | m/s²；0.1～100；`step="any"` | 12 | 只在移動類型顯示；kinematic 物件停用此控制。 |
| 最大衝量 | N·s；0.001～1000；`step="any"` | 10 | 所有三種表單類型均顯示；設定控制／衝量界線。 |
| 逾時 | s；0.1～60；`step="any"` | 10 | 逾時停止並回報狀態，不代表一定可抵達目標。 |

| 釋放後模式 | `dynamicGravity` 受重力／`dynamicNoGravity` 無重力 | `dynamicGravity` | 只在 kinematic 的 `moveAndRelease` 顯示。 |
| 儲存動作 | 按鈕 | — | 無選取物件、fixed 物件或編輯忙碌時停用；帶目前 registry revision 驗證。 |
| 復原／重做動作編輯 | 按鈕 | — | 分別需有可復原／重做歷史，且非編輯忙碌。 |
| 重新綁定目前場景 | 按鈕 | — | 僅場景 pin 過期且非編輯忙碌時可用；不是自動接受已刪除物件。 |
| 匯出動作 | JSON 下載 | 目前 registry | 面板不因編輯忙碌停用匯出；沒有動作載入編輯表單按鈕。 |
| 匯入動作 | JSON 檔案，`application/json,.json` | — | 編輯忙碌時停用；驗證成功後原子替換，失敗保留原資料。限1 MiB、64個動作；scene pin 與物件必須有效，拒絕未知欄位、重複 ID、外來場景。 |
| 各動作的執行／移除 | 按鈕 | — | 執行按鈕在 scene stale 或已有 active run 時停用；其他執行限制由 runtime 明確拒絕。執行會恢復模擬。移除採編輯忙碌規則。 |

| 僅經 JSON 匯入的參數 | 預設／範圍與限制 |
| --- | --- |

| `maxAngularSpeedRadps` | 預設1 rad/s；0.01～3 rad/s。 |
| `maxTorqueImpulseNms` | 預設1 N·m·s；0.001～100 N·m·s。 |
| `positionToleranceM` | 預設0.025 m；0.001～0.25 m。 |

Registry 上限64個動作與執行中最多8個控制器是不同界線；每個物件同時只能有一個控制器。fixed、held、停用／非active物件不可執行，impulse 不接受 kinematic。這些界線不表示面板可同時啟動8個動作：目前列表只允許沒有 active run 時按下執行。

## 17. 音訊匯出（Render）

此面板以完整錄製內的原始聲音決策、路徑與已固定素材，使用真實 `OfflineAudioContext`／既有 `AudioEngine` 產生短片段 float32 WAV。`busy` 指錄製3秒的準備／執行中，或音檔產生中。

| 控制／參數 | 單位、範圍／初始值 | 作用與狀態限制 |
| --- | --- | --- |
| 說明提示 | 開啟／關閉說明 | 說明短錄製、Wet 與 pre-master 分軌語意。 |
| 錄製3秒 | 固定3 s；無時長編輯欄 | production 有 capture port 才顯示；busy 時停用；使用同一 world、Motion hooks 與 recorder。 |
| 保留尾響 | s；0～10；step 0.5；預設2 | busy 時停用。Enter／離焦只提交有效值；空白、非有限值或越界草稿會停用「產生音檔」並顯示原因，按 Esc 可還原已提交值。附加在發聲區間後，不補錄未知的先前歷史。 |
| 各聲源分軌 | 勾選／取消；預設勾選 | busy 時停用；依原始 authored object 群組選取已錄製的聲音 emissions。取消勾選仍輸出 mix、master、dry。 |
| 產生音檔 | 按鈕 | busy、尾響草稿無效，或沒有 `captured` 且 frameCount>0 的完整錄製時停用。無效草稿不會默用前一個已提交尾響值開始新工作；修正或 Esc 還原後才可產生。每次建立固定來源與設定的新工作。 |
| 取消 | 按鈕 | 僅 `rendering` 時顯示；允許取消準備或尚未原子發布的工作。取消／失敗不公開部分新音檔，上一份已完成輸出仍可保留下載。 |
| 傳播後混音（Wet）、主輸出、原始內容（Dry）、分軌 | 每檔下載按鈕；唯讀容量 | 只有完整工作發布後出現；名稱自動產生，沒有改名欄。輸出為雙聲道 float32 PCM WAV，sample rate 沿用錄製設定（44.1或48 kHz），無此面板的 sample-rate/bit-depth 選單。 |
| 下載來源與雜湊清單 | JSON manifest 下載 | 有已發布音檔才顯示；包含 job、configuration、結果、每檔 SHA-256、控制觀測與語意。 |
| 狀態、進度、錯誤、邊界限制 | 唯讀 | 錄製中／已完成數量／可下載；進度只在 rendering 顯示。`tailTruncated` 或 `historyIncomplete` 才顯示「邊界限制」，不是可調參數。 |

每個短片段工作的發聲區間最多30 s；包含 pre-roll、發聲及尾段的 context 最多45 s；最多16份輸出（標準3份加最多13個物件分軌）。估計 working memory 上限256 MiB、編碼輸出上限192 MiB，仍須同時滿足所有預算，並非16份任意長度檔案的保證。過多分軌會明確拒絕，可取消分軌再產生。這些是 backend 驗證界線，不是面板可編輯的預算控制；UI 的「錄製3秒」也不提供任意30秒錄製時長欄。

Wet 為直接聲＋早期反射＋已設定的 Synthetic 尾響、在 master 前；Dry 為傳播／空間化／master 前的內容；Master 套用既定 headroom、monitor、limiter 與安全圖。相同來源、時間、設定與seed的 pre-master stems 可在浮點誤差內加總為 Wet；不可要求各自經非線性 master 處理的分軌必然加總。原生 HRTF 的係數身分為 `browserManagedUnspecified`；本面板沒有自訂 HRTF、listener replacement、獨立 late tap、時間窗、chunks、normalize、master 設定或輸出格式控制，也不宣稱長錄製／ADM或無界渲染。

## 18. 區域（Zones）

區域是獨立的靜態事件範圍，不是剛體、碰撞器或聲學表面。面板最多保存 16 個區域（啟用與停用皆計入）；只有運算暫停、未錄製／重播且處於編輯器時能新增或修改。以下為新建草稿預設；編輯既有區域時讀取既有值。

| 控制 | 單位／範圍 | 新建預設 | 效果、狀態與限制 |
| --- | --- | --- | --- |
| 新增區域 | 最多 16 個 | 未建立草稿 | 開啟一份未儲存草稿；已有草稿、正在提交或達上限時停用。 |
| 區域 ID | 1–64 字；`^[a-z][a-z0-9._-]{0,63}$`；不得與既有 ID 重複 | 最小未使用的 `zone.1`、`zone.2`… | 只允許新建時修改；既有 ID 為唯讀，不能藉編輯改名。 |
| 名稱 | 1–80 字，不能全空白 | 繁中「新區域」／英文「New zone」 | 儲存會去除首尾空白；顯示名稱不取代穩定 ID。 |
| 形狀 | 軸對齊方盒 `aabb`／球形 `sphere` | `aabb` | 方盒不提供旋轉；切換形狀後只儲存目前形狀對應的尺寸。 |
| 啟用（草稿） | 布林 | `true` | 隨「儲存區域」一起提交；停用只停止進出判定，不刪除區域或引用。 |
| 中心位置 X／Y／Z | m；各軸 −200–200；`step="any"` | `[0, 1, 0]` | 必須為有限數值；世界座標，+Y 向上。 |
| 半尺寸 X／Y／Z | m；各軸 0.05–50；`step="any"` | `[1, 1, 1]` | 僅方盒顯示；完整邊長為各半尺寸的 2 倍。 |
| 半徑 | m；0.05–50；`step="any"` | `1` | 僅球形顯示。 |
| 邊界遲滯 | m；0–0.25，且嚴格小於最小半尺寸／半徑；`step="any"` | `0.02` | 進入用內縮界，離開用外擴界；不是改變線框顯示尺寸。 |
| 儲存區域 | 動作／表單提交 | — | 有效且未過期時原子提交；無效、stale、正在提交或編輯狀態不允許時停用。成功須收到較新 scene revision 與相符區域內容；否則保留草稿並顯示錯誤。 |
| 取消草稿／Esc | 動作 | — | 放棄未提交值；提交中停用。IME 組字中的 Esc 不會取消。 |
| 清單中的啟用／停用 | 布林，即時提交 | 既有值 | 沒有草稿時可直接提交切換；同樣受暫停／編輯器、revision 與 registry guard 約束。 |
| 編輯／刪除 | 每區域動作 | — | 有草稿或提交中皆停用。刪除會先檢查所有規則；trigger 或 emitter attachment 引用此區域時回 `ZONE_IN_USE`，列出 `profileId/ruleId`，必須先改選／移除引用。 |
| 全域 Undo／Redo | 共用場景動作 | — | 成功新增、更新、啟停或刪除均進入共用場景歷史；區域面板沒有另外一套 Undo 按鈕。 |

草稿保存建立時的專案識別、scene revision 與區域 registry pin；即使輸入欄位仍可修改，場景或區域清單已變更時也不能儲存，需取消後重新編輯。錯誤輸入會保留原始字串並顯示驗證訊息，不會悄悄換回舊數值。區域資料隨正式 Scene／Project 儲存與匯入，面板沒有獨立區域 Import／Export 按鈕。

`OnEnterZone`／`OnExitZone` 規則必須指定明確 `zoneId`。新增規則只列啟用區域；既有規則仍顯示其已停用的原引用，不能把停用誤認為刪除。聲音預設仍附著物件；只有明確選擇 zone attachment 時才使用區域中心錨點，停用區域的既有中心錨點仍有效。

事件模型標為 **Derived**：以每個權威固定步完成後的有效物件中心取樣，不測整個碰撞器重疊，也不做連續掃掠。若名義邊界距離為 `d`、遲滯為 `h`，外部物件在 `d ≤ −h` 進入，內部物件在 `d > +h` 離開。開始／重設、重建、區域變更或位置不連續的首步只建立基準，不偽造進出；保持位置連續的 mode 切換或 Motion release 不因模式變更而抹去真實跨界。單一步內快速穿越、兩端取樣都在外時可以沒有事件。最多 16 區域 × 256 poses；既有加新增 events 的單步上限 2048，超量明確拒絕，並非效能承諾。

編輯器中的線框只顯示**名義範圍**；FPS 或重播時隱藏。啟用與停用用不同顏色／透明度；線框沒有 picking／碰撞／聲學作用，不阻擋選取後方物件。球形線框的 24×16 顯示分段不是事件判定的近似球面，producer 使用解析距離。

## 19. Agent 提案與實驗流程

Agent 分頁同時呈現「操作提案」與由 Host 計算的「實驗流程」。兩者互不等同：提案需明確套用；建立基準／候選流程本身不呼叫模型，也不自動套用提案。

| 控制／資料 | 單位、範圍與初始值 | 效果、狀態依賴與限制 |
|---|---|---|
| 執行方式（AI 執行方式） | `offline`「離線工具（非模型）」／`meta`「Meta Model API」；預設 `offline` | 載入／執行中停用切換。離線模式只接受本機受限指令，不是模型輸出。Meta 模式只有在伺服器狀態 `ready` 才能提交提案；未知／載入／blocked／error 不會假裝成功。 |
| 重新檢查伺服器狀態 | 按鈕，無數值 | 重新讀公開 provider 狀態；提案載入或狀態檢查中停用。不是送出 planning 請求，也不提供 key／model／budget 編輯器。 |
| 實驗指令 | 多行文字，初始空；原生 `maxlength=4000`（UTF-16 碼元） | 空白經 trim 後不可提交；一般 Enter 換行；Ctrl／⌘+Enter 提交；組字期間不提交。文字欄仍可輸入時，不代表提交 gate 已開放。 |
| 產生操作預覽 | 按鈕 | 非空白、未 loading 且 provider 可用才可送出；只產生已驗證差異，尚未改變 Scene。越權 OS／程式／key 請求與未辨識離線要求會明示拒絕。 |
| 已驗證的操作差異 | 可鍵盤聚焦的唯讀文字 | 只有 preview 存在時顯示；不是可直接編輯的 JSON 輸入欄。 |
| 套用操作／暫停並套用操作 | 按鈕 | preview 存在、`canApply` 且未 loading 時可用；running 時先暫停再透過相同 Domain／revision 守衛原子套用。Scene 已改動的過期預覽會拒絕，不覆寫新修改。 |
| 取消預覽 | 按鈕 | preview 存在且未 loading 時可用；清除未套用提案，不修改 Scene。這是提案取消；執行中的實驗另用下列取消流程。 |
| 復原上次 AI 套用 | 按鈕 | `canUndo=true` 且未 loading 才可用；透過提案 Host 復原最後一次已套用的 Scene／Motion 交易並保留 revision 歷史，不倒轉已發生的物理與聲音。 |
| 基準實驗長度 | s；UI min `1`、max `10`、step `1`；預設 `3` | Enter／離焦提交有效有限值；Escape 回復尚未提交的輸入。spinner step 是 1；Host 另要求時長為 `1/60 s` 整數倍（例如 `1.01` 不通過），不靜默四捨五入。running／cancelRequested 時停用。 |
| 建立基準實驗 | 按鈕 | 未 busy 時執行目前 Scene 的有限 `RunSimulation → CaptureExperiment → AnalyzeAcousticResults`。新一輪基準成功完成後替換流程目前基準，保留工具 artifact 的不可變來源。執行前停止預覽並暫停互動模擬。 |
| 以相同運動比較目前材質 | 按鈕 | 未 busy 且已完成可比較基準才可用。沿用基準設定與原運動 run trace，建立候選後要求 matched motion 比較；Scene ID／seed、幾何／運動／聲源等相容性由 Host 驗證，修改材質並不免除其他固定條件。 |
| 取消實驗流程 | 執行中才顯示的按鈕 | running 時提出安全取消；`cancelRequested` 時停用重按並繼續顯示等待，直到 Host 確認，不能把提出取消當作已終止。已完成步驟不偽造撤回。 |
| 可追溯結果 | 唯讀表格：metric ID、值、單位、頻率 Hz | 只顯示成功 Host 結果中與 citation 的 run／metric／artifact 匹配的指標；缺值顯示「未提供」，不補零或虛構 RT60。 |
| 步驟與結果來源／原始 Host 說明 | 原生 details／summary 折疊 | 顯示基準／候選 run ID、工具、結果狀態、錄製 ID、原始說明與 metric/artifact citations；沒有手動編輯或匯入／匯出按鈕。 |
| 說明控制 | 執行方式、Undo、指令、操作預覽、實驗流程的 HelpTip | 滑鼠與焦點可顯示對應說明；說明按鈕不是額外參數。 |

流程預設取樣率 `48000 Hz`、分析 `directArrivalTimeS` 與 `rt60S`、頻帶 `[1000 Hz]`、`timeStepS=1/60`、反射階數 `1`，這些是此面板的固定程式設定，沒有對應可編輯欄位。Meta 費用與帳號／網路／live gate 由 server 管理；目前驗收使用費用上限 0 的環境，不把離線閉環或公開 status GET 說成付費 Meta live 通過。介面沒有 API key、模型名稱、context、支出上限編輯器，亦無任意執行 OS／Repository 的入口。

## 20. 音訊效能觀測（Diagnostics）

此面板用來讀取 JavaScript 控制執行緒的成本及瀏覽器原生輸出計數，只有一個可改變觀測狀態的參數。啟用聆聽以前 diagnostics 尚不存在，數值顯示 `—`；該情況不代表量測為零。

| 控制／狀態 | 範圍與初始值 | 效果與限制 |
|---|---|---|
| 啟用成本觀測 | checkbox `false/true`；未建立音訊時 unchecked 且 disabled；AudioEngine 建立 diagnostics 預設 `true` | 啟用聆聽後才可操作。關閉停止新增觀測、保留既有控制計數／樣本，顯示「觀測已停用；顯示保留資料」；重新啟用恢復採樣，原生輸出 delta 視窗重新起算，不能把間隔算成零。 |
| 更新成本與分項計數 | details／summary；初始收合 | 展開／收合 11 列唯讀明細；沒有數值輸入欄。 |
| 控制執行緒觀測說明 | 可聚焦標籤 + HelpTip | 解釋範圍與 p95；不修改量測。 |
| 延後起音、接受／拒絕影格、瀏覽器原生輸出說明 | 3 個 HelpTip 按鈕 | 說明門檻、計數單位、原生視窗規則；非參數。 |
| 瀏覽器原生輸出狀態 | 唯讀 `NOT_OBSERVED / UNSUPPORTED / WARMUP / AVAILABLE / COUNTER_RESET` | 原生數值只在 `AVAILABLE` 顯示。未提供、首筆與重置保留其狀態，不以零冒充；只比較同一 AudioContext 的相鄰觀測。 |
| 觀測已停用；顯示保留資料 | 唯讀狀態文字，僅 enabled=false | 表示舊資料仍可閱讀，不表示已採到新樣本。 |

| 唯讀讀值（共 19 項） | 單位／意義 |
|---|---|
| 延後起音／起音總數 | 次／次；超過原訂起音時間 `1 ms` 才計為 late；不含聲學傳播或裝置延遲 |
| 接受／拒絕的音訊影格 | 影格數／影格數；引擎消費分類，與求解器送達批次不同 |
| 影格消費 p95、路由控制 p95 | ms（2 張摘要卡） |
| 本視窗輸出中斷、本視窗中斷時間、觀測視窗、裝置輸出延遲 | 次、ms、ms、ms（4 張摘要卡）；只在原生計數可用時呈現 |
| 起音延後 p95、Listener 控制 p95 | ms（明細 2 列） |
| 求解器送達批次、送達處理 p95 | 批次數、ms；未接入送達觀測時明示而不補值（明細 2 列） |
| IR 頻率形狀建立、IR 頻率形狀重用 | 次數（明細 2 列） |
| 純量增益更新／略過、延遲更新／略過、方向更新／略過 | 次數配對（明細 3 列） |
| 保留樣本、AudioContext 世代 | frame-consumer 已保留筆數／容量 `128`；context generation（明細 2 列） |

面板沒有 refresh、counter reset、p95／sample-capacity／native-status 編輯器、匯入或匯出按鈕。p95 僅描述最近最多 `128` 筆保留樣本；本頁數字不能代替 DSP callback CPU、PCM 連續性、600 秒效能門檻、實體聽測或聲壓校準。
