If a real GPU browser still stutters, follow the order of the [performance and buffering review](13-performance-review/OPTIMIZATION_ROADMAP.md): first attribute the audio dropouts and costs (RLAB-TASK-PERF-20261101-001), then decide the next step from the data; moving the physics simulation into a Worker is one P2 candidate there (RLAB-TASK-PERF-20261101-009) that needs attribution evidence first, and this round does not implement it.
