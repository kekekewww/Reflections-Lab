# 正常比例真人測試指引

本頁適用 R17 真人測試版，產品來源截點為 `cde1e2b0ed7c57228bfa64b01c262b6eeab3cba1`；後續文件截點可不同。自動功能檢查與600秒量測已保存；高負載性能未達標，詳見[已知限制](../KNOWN_LIMITATIONS.md)，不代表完整第一版完成。使用者已移除原生200%縮放門檻；保持瀏覽器正常100%比例即可。舊交接中的限時指令與測試網址已失效，請勿重用。

## 一般操作：大約五分鐘

1. 在專案目錄執行 `npm run dev`，以 Chrome 開啟終端機印出的本機網址。保持100%比例，選繁體中文或英文；確認場景區夠大，主要按鈕可見。
2. 用滑鼠選取預設球體，確認右側顯示其設定。收合／展開下方分析區，拖曳左右面板邊界；確認場景仍可使用，沒有文字蓋住按鈕。
3. 開始運算，觀察球體受重力落下、碰撞及反彈。按暫停，物體應停止；繼續後恢復。不要把此簡單觀察當作數值物理驗證。
4. 在場景上方按「進入第一人稱／Enter first person」，依畫面提示進入控制。若已鎖定滑鼠但仍顯示暫停，按 **Enter 開始**；運算中 Enter 是暫停。用 **W／S 前進／後退、A／D 左移／右移、滑鼠轉向**。按住移動鍵約一秒再放開，角色應移動且停止；進入那一下不能同時投擲或放置物件。
5. 按 Esc，應釋放滑鼠並安全暫停。再進入一次；切換到其他視窗後回來，應先要求明確繼續。若瀏覽器拒絕滑鼠鎖定，記錄可見提示，並測試畫面提供的不鎖定控制按鈕。
6. 嘗試鍵盤 Tab 導覽與輸入框打字；輸入文字時不能意外移動角色、投擲或建立物件。中英文介面應保留同一場景與錄製資料。

回報「哪一步、按了什麼、預期、實際」；第一人稱若仍失敗，請附 Chrome 版本、畫面上的錯誤文字，以及是否成功看到鎖定提示。沒有觀察的項目寫「未測」，不用猜測通過。

基本移動通過後，可選測抓投：靠近可移動球體、準星瞄準後按 **E 抓取**，持有時 **左鍵投擲**，或再按 **E 釋放**。物體太遠、被擋住或為固定物時，先記錄畫面原因。滑鼠鎖定被拒絕時，依畫面明確啟用免鎖定操作，再使用繼續運算、前後左右及抓取／投擲按鈕；不要一直重按進入。Ctrl+C 可在啟動用的終端機結束本機服務。

## 聲音：先耳機，再喇叭

已知可用裝置是 Austrian Audio Hi-x65 與 ADAM Audio D3V。每次換裝置先靜音並暫停；從低實體音量開始。請分別記錄實際 Windows 輸出裝置、DAC／音效介面及音量，不知道就寫 UNKNOWN。

一般體驗可在暫停時按「啟用聆聽／Enable listening」，再開始運算。先確認持續聲與碰撞聲，再移動 Listener 聽方向變化；單純旋轉編輯器視角不會移動 Listener。比較 Raw reference 與 Simulated 時，音量差本身不代表錯誤。請觀察暫停／繼續、移動與切換模式時，是否有爆音、突兀音量跳變或斷音；不舒服時立即靜音停止。

需保存裝置回呼證據時，改用[已凍結聽測工具](../../tests/browser/device-hearing-v3/README.md)，依[原始聽測協定](../../tests/browser/device-hearing/manual-probe-protocol.json)由協作者協助執行。此流程會核對固定版本並記錄真實回呼；不要同時操作一般開發頁或其他預聽頁，以免選錯音訊來源。它不會替你判斷是否好聽，也不會自動知道 DAC、實體音量或校準聲壓。
