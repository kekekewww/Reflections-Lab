# 正常比例真人測試指引

本頁適用 R19 重測版（修補 R18 真人回報），產品來源截點為 `5e56260b1a9242e29c4afe6ce393bd8a37986320`；後續文件截點可不同。其後 R20 依自動重測修補了 F 固定與放置的狀態提示、B 鍵建造預覽、狀態列英文、曲面物體的聲學說明與 WebGL 備用文字；請以本分支最新版本測試，完整範圍見[完整測試流程](FULL_TEST_PROCEDURE.md)。R17 的自動功能檢查與600秒負面性能結果仍保留，高負載性能未達標，詳見[已知限制](../KNOWN_LIMITATIONS.md)，不代表完整第一版完成。使用者已移除原生200%縮放門檻；保持瀏覽器正常100%比例即可。舊交接中的限時指令與測試網址已失效，請勿重用。

R19 的三項變更：進入第一人稱的那一下點擊就開始操作，不需再按 Enter；點選物件後可在場景中直接移動、旋轉、縮放；預設監聽音量提高約 23 dB（數位電平），**開始前請先調低 Windows／DAC／喇叭實體音量**。

## 一般操作：大約五分鐘

1. 在專案目錄執行 `npm run dev`，以 Chrome 開啟終端機印出的本機網址（通常是 `http://127.0.0.1:5173/`）。保持100%比例，選繁體中文或英文；確認場景區夠大，主要按鈕可見。
2. 在場景中直接點選球體：滑鼠移到物件上時游標應變成手指，點選後出現選取外框與變形工具，右側顯示其設定。在「準備就緒」或「暫停」時，用場景上方的「移動／旋轉／縮放」切換工具並拖曳彩色把手；放開後物件應更新一次，按復原應回到原狀。拖曳中按 Esc 應取消且物件不變。球體縮放會保持等比例。運算中工具會隱藏並顯示「暫停後可拖曳／縮放」。修訂版本、座標、聲線圖例與阻擋候選已收進場景下方的「視圖資訊」，需要時再展開；也請收合／展開下方分析區、拖曳左右面板邊界，確認沒有文字蓋住按鈕。
3. 開始運算，觀察球體受重力落下、碰撞及反彈。按暫停，物體應停止；繼續後恢復。不要把此簡單觀察當作數值物理驗證。
4. 在場景上方按「進入第一人稱／Enter first person」。滑鼠鎖定成功後應直接開始運算，提示顯示「WASD 移動 · 滑鼠轉向 · Enter 暫停 · Esc 釋放滑鼠」。用 **W／S 前進／後退、A／D 左移／右移、滑鼠轉向**；按住移動鍵約一秒再放開，角色應移動且停止。進入那一下不能同時投擲或放置物件。按 Enter 會暫停；暫停時點擊畫面或再按 Enter 應繼續。
5. 按 Esc，應釋放滑鼠並安全暫停，提示「滑鼠已釋放」。約一秒後點擊畫面（或「啟用滑鼠控制」）應重新鎖定並繼續；Chrome 在剛按 Esc 後會短暫拒絕重新鎖定，這是瀏覽器限制，再點一次即可。切換到其他視窗後回來，應維持暫停，直到你點擊畫面或按 Enter。若瀏覽器拒絕滑鼠鎖定，記錄可見提示，按「啟用免鎖定操作」與「開始第一人稱操作」，再點選畫面，以 WASD、方向鍵與 Enter 操作，或使用下方按鈕。
6. 嘗試鍵盤 Tab 導覽與輸入框打字；輸入文字時不能意外移動角色、投擲或建立物件。中英文介面應保留同一場景與錄製資料。

回報「哪一步、按了什麼、預期、實際」；第一人稱若仍失敗，請附 Chrome 版本、畫面上的錯誤文字，以及是否成功看到鎖定提示。沒有觀察的項目寫「未測」，不用猜測通過。

基本移動通過後，可選測抓投：靠近可移動球體、準星瞄準後按 **E 抓取**，持有時 **左鍵投擲**，或再按 **E 釋放**。持有中按 Esc 後重新鎖定，會先維持暫停，點擊畫面或按 Enter 才繼續，以免誤投擲。物體太遠、被擋住或為固定物時，先記錄畫面原因。瞄準物件按 **F** 固定後會安全暫停，按 Enter 或點擊畫面應可繼續。Ctrl+C 可在啟動用的終端機結束本機服務。

## 聲音：先耳機，再喇叭

已知可用裝置是 Austrian Audio Hi-x65 與 ADAM Audio D3V。每次換裝置先靜音並暫停；從低實體音量開始。請分別記錄實際 Windows 輸出裝置、DAC／音效介面及音量，不知道就寫 UNKNOWN。

R19 將預設監聽由約 −15 dB 提高到 0 dB，主混音保留量由約 −14 dB 改為 −6 dB；自動量測的預設場景數位輸出峰值約由 −51 dBFS 提高到 −29 dBFS。這只是數位電平，不是校準聲壓。Monitor 滑桿現以 dB 顯示，範圍 −40 至 +12 dB；靜音按鈕仍獨立。limiter 之後另加輸出安全上限，極端設定下數位輸出也不超過全刻度，但這不是聽力安全保證。請回報預設是否仍太小、太大或合適。

一般體驗可在暫停時按「啟用聆聽／Enable listening」，再開始運算。先確認持續聲與碰撞聲，再移動 Listener 聽方向變化；單純旋轉編輯器視角不會移動 Listener。比較 Raw reference 與 Simulated 時，音量差本身不代表錯誤。請觀察暫停／繼續、移動、調整 Monitor 與切換模式時，是否有爆音、突兀音量跳變或斷音；不舒服時立即靜音停止。

需保存裝置回呼證據時，改用[已凍結聽測工具](../../tests/browser/device-hearing-v3/README.md)，依[原始聽測協定](../../tests/browser/device-hearing/manual-probe-protocol.json)由協作者協助執行。此流程會核對固定版本並記錄真實回呼；不要同時操作一般開發頁或其他預聽頁，以免選錯音訊來源。它不會替你判斷是否好聽，也不會自動知道 DAC、實體音量或校準聲壓。
