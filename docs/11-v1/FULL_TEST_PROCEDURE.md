## 測試前準備

1. 確認 Node／npm 版本符合 `.node-version` 與 `package.json`；若沒有 `node_modules`，先在專案目錄執行一次 `npm ci`。
2. 在專案目錄執行 `npm run dev`。它同時啟動 Vite 網頁（`http://127.0.0.1:5173/`）與本機 API 服務；在啟動它的終端機按 Ctrl+C 結束。若由代理啟動，請代理停止。
3. 使用 Chrome，顯示比例100%，視窗最大化。記下 Chrome 版本（網址列輸入 `chrome://version`）與 Windows 版本。
4. **先調低 Windows／DAC／喇叭的實體音量**，先用耳機。R19 預設監聽比 R18 大約 23 dB（數位電平）。
5. 想要乾淨狀態時，可用新的 Chrome 設定檔或無痕視窗；無痕視窗關閉後本機專案與錄音會消失，所以 B11 的重新整理測試要在同一個視窗內完成。
6. B11 需要一個短 PCM／float WAV（建議1至5秒，上限120秒），請用你有權使用的檔案。本機若有 `.cache/human-test/test-tone-440hz-1s.wav`，那是自行合成的1秒 440 Hz 正弦波，沒有第三方權利，可直接使用。

預設場景是一個6公尺寬、4公尺高、8公尺深、前方開放的示範空間：木質地板、硬質後牆與左右牆、會受重力的金屬球 `ball`，以及持續播放 220 Hz 測試音的喇叭 `speaker`。Listener 獨立放在場景前方。所有材質都是 Synthetic 示範值。

### B1 啟動、語言與版面

1. 開啟 `http://127.0.0.1:5173/`，預設應為繁體中文。用頂列「介面語言」切到 English 再切回；場景、聲音設定與錄音不應改變。
2. 切換「建立場景」、「互動實驗」、「檢驗比較」三個工作區；場景與模擬狀態應保留。
3. 拖曳左右面板邊界，收合再展開下方分析區；確認沒有文字蓋住按鈕。
4. 展開場景下方「視圖資訊」，應看到修訂版本、座標、聲線圖例與阻擋候選；收合後場景區變大。
5. 編輯器視角：Alt＋左鍵旋轉、中鍵平移、滾輪縮放；選取物件後按「對準選取」，觀察相機應對準它，Listener 不動。
6. 說明文字（R21）：Inspector、場景清單、Monitor 與分析區不應再出現整段說明文字；說明改成欄位或標題旁的 ⓘ。滑鼠移到 ⓘ 上、或用 Tab 聚焦時應顯示說明，按 Esc 或移開即消失，提示框不超出視窗。停用的按鈕也應能用滑鼠懸停或聚焦看到停用原因。欄位名稱、數值、狀態、錯誤與安全警告仍應直接可見。中英文各看一次。
7. 選取球體，Inspector 的尺寸應只有「直徑」一欄；選取或新增膠囊，應有「直徑」與「高度」兩欄，把高度改得比直徑小時，欄位保留輸入並顯示原因，切換語言後原因也跟著翻譯。

### B2 場景直接操作（R19 優先）

1. 在「準備就緒」或「已暫停」狀態，把滑鼠移到球上，游標應變成手指；點選後出現選取外框與變形工具，右側 Inspector 顯示其設定。也從左側物件清單點選，結果應相同。
2. 用場景上方「移動」拖曳彩色箭頭；放開後物件只更新一次。按「復原場景命令」應回到原位，「重做場景命令」再回來。
3. 選取喇叭，用「旋轉」拖曳圓環；選取球，用「縮放」拖曳，球應保持等比例。
4. 拖曳中按 Esc，物件應回到拖曳前且沒有新增復原紀錄。
5. 按「開始運算」，變形工具應隱藏並顯示「暫停後可拖曳／縮放」；按「暫停」後工具回來。
6. 放開把手後立刻點另一個物件：若上一筆修改尚未完成提交，這一下點擊會被忽略，再點一次即可選取；不應選錯物件。快速連續拖曳不應產生兩筆重疊的修改。

### B3 物理運算

1. 按「開始運算」，球應受重力落下、碰撞並反彈。按「暫停」應停止；「繼續運算」後恢復。
2. 按「重設」，物理回到目前場景文件的初始狀態；這不會復原場景命令，也不會刪除已封存錄音。
3. 暫停後選取球，在 Inspector 的 Body Mode 改為「Dynamic · 無重力」再運算：球不再落下但仍會碰撞。改為「Fixed · 固定」：球不受一般力而移動。測完用復原改回。
4. 運算中嘗試新增物件，應顯示「請先暫停再新增物件」；暫停後用左側「物件庫」新增方塊、球體或膠囊，應出現在場景中且可復原。
5. 這只是行為觀察，不代表數值物理驗證。

### B4 第一人稱（R19 優先）

1. 按場景上方「進入第一人稱」。滑鼠鎖定成功後應直接開始運算，不需要再按 Enter；畫面底部的一行提示列列出目前可用的按鍵（例如「左鍵 抓取 · 按住右鍵 預覽，放開 放置 · L 物件庫 · Enter 暫停 · Esc 釋放滑鼠」），不遮住準星。進入那一下不應同時抓取、投擲或放置物件。
2. 用 W／S 前進後退、A／D 左右平移、滑鼠轉向；按住 Shift 加速。按住移動鍵約一秒再放開，角色應移動並停止。
3. 按 Enter 應暫停，提示「已暫停 · 點擊畫面或按 Enter 繼續 · Esc 釋放滑鼠」；點擊畫面或再按 Enter 應繼續。
4. 按 Esc 應釋放滑鼠並安全暫停。約一秒後點擊畫面或「啟用滑鼠控制」應重新鎖定並繼續；Chrome 在剛按 Esc 後會短暫拒絕重新鎖定，再點一次即可。
5. 用 Alt+Tab 切到其他視窗再回來，應維持暫停，直到你點擊畫面或按 Enter。
6. 若瀏覽器拒絕滑鼠鎖定：記錄提示，按「啟用免鎖定操作」與「開始第一人稱操作」，點選畫面後用 WASD、方向鍵與 Enter，或用下方按鈕操作。
7. 測完按「離開第一人稱」。

### B5 抓取、投擲、固定與建造

需先通過 B4。

1. 走到球三公尺內，用準星瞄準按**左鍵**抓取；移動時球應跟著且仍會碰撞，不穿牆。滾輪調整持有距離。持有時按左鍵投擲，或按**右鍵**放下（E 仍可抓取或放下，但不需要）。
2. 持有時按 Esc，重新鎖定後應維持暫停，點擊畫面或按 Enter 才繼續，以免誤投。
3. 瞄準牆按左鍵，應顯示「第一個命中物件已固定、受控或超過抓取預算」；離太遠時應顯示「三公尺內沒有可抓取物件」。
4. 瞄準球按 F 固定，球應變為固定並安全暫停，狀態列顯示「已固定；另按繼續才恢復模擬」；按 Enter 或點擊畫面繼續後，這段提示應消失。
5. 建造：沒有持有物件時**按住右鍵**，應出現半透明放置預覽並跟著準星移動。對準地面或牆時貼附表面，對準空處時停在預覽距離的空中，提示列顯示「貼附表面」或「空中（無重力）」。滾輪調整距離；按 R 後左右移動滑鼠旋轉預覽。**放開右鍵**即放置：物件立即可操作，不需要確認、啟用或另按繼續，運算維持原本狀態，狀態列顯示「物件已放置，可直接操作。」快速點一下右鍵也會放置。
6. 空中放置的物件應停在空中、仍會碰撞（被球或投擲物撞到才移動）；貼附地面放置的物件受重力。放置後可立刻用左鍵抓取它，或繼續按住右鍵放下一個。
7. 按住右鍵時按左鍵或 Esc，預覽消失且不放置。對準自己腳下或超出 3.5 m 範圍時放開右鍵，應顯示無法放置的原因且預覽消失；之後左鍵仍正常抓取，不會卡在預覽中。
8. 到物件庫（L，或按 Esc 後在左側「物件庫」）選擇球體或膠囊，回到第一人稱後按住右鍵，預覽應改為該形狀。
9. 按 Esc 釋放滑鼠後按 Ctrl＋Z，剛放置的物件應消失（每次放置一筆復原）。
10. 開始錄製後在第一人稱按住右鍵，應提示「錄製（含暫停）或重播期間無法預覽或放置；請先結束錄製或返回即時場景。」錄製不受影響。

### B6 聲音與預設音量（R19 優先）

1. 確認實體音量已調低。保持「準備就緒」或「已暫停」，在下方 Monitor 列按「啟用聆聽」。啟用聆聽不會自動開始運算。
2. 「監聽音量」應以 dB 顯示，預設 0 dB，範圍 −40 至 +12 dB。「音訊緩衝」預設「穩定」，旁邊顯示裝置輸出延遲（ms）與「輸出中斷 N 次」。
3. 按「開始運算」，應聽到喇叭的持續測試音與球的碰撞聲。請回報預設音量是太小、合適還是太大，以及當時的 Windows 音量與輸出裝置。
4. 斷音（R21 重點）：在「穩定」下運算約 1 分鐘，期間進入第一人稱走動、轉向、抓取與放置物件；回報是否還聽到斷斷續續，以及結束時「輸出中斷」的次數。再切換到「平衡」與「低延遲」各試一次：切換時聲音應短暫淡出後恢復，不應出現兩層聲音或爆音；記下各自的中斷次數與聽感。錄製中切換應被拒絕並說明原因。
5. 切換「Simulated」與「Raw 參考」：Raw 參考是置中、無環境傳播與 HRTF 的乾聲，兩者音量不同本身不代表錯誤。
6. 方向與距離：單純旋轉編輯器視角不會移動 Listener。進入第一人稱後 Listener 會自動跟隨頭部，左側「Listener / 環境」顯示「跟隨 FPS」；走動、轉向，聽方向與距離變化。離開第一人稱後回到「獨立位置」。
7. 在暫停／繼續、移動、調整監聽音量與切換模式時，留意爆音、突兀音量跳變或斷音。
8. 結束時按「暫停」與「靜音監聽」；靜音只影響監聽，不會暫停物理。

### B7 材質與反射

1. 暫停。在下方分析區打開「聲學路徑」分頁，應看到直達與「反射」路徑，含路徑 ID、距離、傳播延遲與振幅比。可對照「視圖資訊」中的聲線圖例（Listener / Direct、Reflection）與「聲線來自求解器」計數。
2. 選取後牆 `wall.back`，在 Inspector「聲學材質」區的「表面材質」由「硬質表面 · Synthetic」改成「吸音表面 · Synthetic」。路徑重新求解後，若路徑表有經過後牆的反射，其振幅比應下降；以 Simulated 監聽時反射感應改變，可能不明顯。按復原改回。
3. 目前聲學幾何只計入方塊，球體與膠囊不會遮擋或反射聲線；選取球時，Inspector 應停用「表面材質」與「聲學角色」，原因可在旁邊的 ⓘ 懸浮提示中看到。從物件庫新增一個方塊，用 B2 的移動工具放到喇叭與 Listener 之間，「聲學路徑」中的直達路徑應消失；也在「視圖資訊」查看阻擋候選。測完復原。
4. 在左側選「Listener / 環境」，於 Inspector 把「傳播介質」改為「Vacuum · 無空氣傳播」。場景應顯示「真空 · 無空氣聲傳播」，路徑區說明真空沒有空氣聲傳播，而不是顯示 0；機械碰撞仍存在。測完改回「Air · 空氣」。
5. 這些材質是手工示範係數，不是量測值；幾何傳播是數值近似，HRTF 與尾響是感知近似。請只記錄你看到與聽到的現象，不判斷科學正確性。

### B8 規則預聽

1. 運算讓球撞擊後暫停。在「事件與錄放」選取一筆已接受的撞擊聲音事件。
2. 選取球，在 Inspector 的對應撞擊規則按「場景聲學預聽」，應聽到該規則在目前靜態場景的聲音；展開「預聽快照與來源」查看來源。
3. 按「停止預聽」。確認模擬時間、錄音與事件都沒有因預聽而前進。
4. 未選取有效事件時，應看到需要真實接觸事件的說明，而不是自行捏造輸入。

### B9 錄製與重播

1. 按「重設」，在「事件與錄放」按「● 開始錄製」，再「開始運算」約10秒，讓球彈跳幾次，然後按「■ 停止錄製」，紀錄應封存。自動測試在無 GPU 的 headless Chrome 中錄製會反覆因負載暫停，同日錄到的秒數差異很大；請記錄真實 Chrome 上的暫停次數與實際錄到的秒數。
2. 按「▶ 重播紀錄」，應顯示「重播已錄物理軌跡；未重新執行Rapier」。在時間軸上前後跳轉，畫面與聲音應跟著；繼續時不應重複發出舊碰撞聲。
3. 按「結束重播」，應回到暫停的即時場景。
4. 按「匯出已封存錄製」，應下載錄製 JSON；它與專案 JSON 分開保存。
5. 若出現「固定步負載超限，已暫停；未丟棄錄製 tick」，記錄當時場景與時間；這屬於已知性能限制，可繼續逐批處理或明確停止。

### B10 A/B 比較

1. 有一筆已封存錄製後，在「實驗比較」按「保存 A 快照」。
2. 只改一項聲學條件，例如把後牆改成「吸音表面 · Synthetic」，再按「保存 B 快照」與「檢查並比較」。B 是重新評估同一段錄製運動，不是新的物理運算。
3. 閱讀相容性、單位、分析窗、樣本數、來源與不可用原因，再看差值；缺少或不相容的資料不等於 0。
4. 行為 A/B：改回材質，改為調整球撞擊聲規則的增益或音高，再比較一次。
5. 不要改質量、摩擦、彈性或幾何來做材質比較，那會改變物理刺激，需要新的運算。

### B11 儲存、匯入與匯出

1. 做一個可辨識的修改（例如移動球），按「儲存專案」或 Ctrl+S。重新整理頁面，按「載入本機已儲存的專案」，修改應還原。
2. 按「匯出專案」，Chrome 會下載專案 JSON。
3. 再做另一個修改，按「匯入專案 JSON」，選剛才的檔案，應先出現檢視對話框；按「套用並開啟專案」後回到匯出時的狀態。
4. 試著匯入一個非專案檔（例如 WAV 或文字檔），應被拒絕且目前專案保持不變。
5. 暫停後勾選「我確認有權使用匯入的音檔」（可能在收合區內），按「匯入聲音」選擇 WAV，應通過檔案大小、結構、長度與解碼驗證。可選：把它指定給某個聲音規則並試聽。
6. 專案 JSON 不包含 WAV 與錄音本體；清除瀏覽器資料後它們可能消失。

### B12 離線實驗助理

1. 在下方分析區打開「Meta 實驗 Agent」分頁，確認目前是預設的「離線工具（非模型）」。
2. 輸入「新增一顆無重力發聲球」，應出現操作預覽而尚未套用。按「套用操作」（運算中會顯示「暫停並套用操作」）後，應顯示提案已套用並建立新 revision；按復原應移除它。
3. 輸入 `ball impact audio quiet`，應出現球撞擊聲的預覽。
4. 輸入無法辨識的文字，應看到離線指令尚未辨識的說明，並建議改用 Inspector。
5. **不要切到 Meta Model API 送出請求**：本專案授權的三次 live 請求已用完，也不要重設帳本。「重新檢查伺服器狀態」只讀狀態，不會推論。

### B13 鍵盤、輸入法與焦點

1. 用 Tab 依序瀏覽主要控制，應看得到焦點位置，且不會跳過重要按鈕。
2. 在 Inspector 數值欄或助理輸入框打字時，W／A／S／D、E、B、F 不應移動角色、抓取、建造或固定物件。
3. 用注音輸入法在助理輸入框組字時，角色不應移動；組字中按 Enter 只確認文字。
4. 第一人稱等待鎖定時按 Tab 或點進文字欄，應取消等待中的進入，不應之後突然開始移動。這段等待通常很短，來不及操作時寫「未測」。

### B14 裝置聽測

需要協作者，依[已凍結聽測工具](../../tests/browser/device-hearing-v3/README.md)與[原始聽測協定](../../tests/browser/device-hearing/manual-probe-protocol.json)進行。先用 Hi-x65 耳機，再用 D3V 喇叭；每次換裝置先靜音並暫停，從低實體音量開始。記錄實際 Windows 輸出裝置、DAC／音效介面與音量，不知道寫 UNKNOWN。執行時不要同時開著一般開發頁或其他預聽頁，以免選錯音訊來源。

## D. 結束與後續

1. 在啟動 `npm run dev` 的終端機按 Ctrl+C 停止服務；若由代理啟動，請代理停止。
2. 自動測試留下的未追蹤紀錄保留，不要刪除。
3. 回報交給代理後，會另建回報紀錄並更新 RLAB-TASK-0022；失敗項目先重現再修補。回報、自動測試、性能數字、授權與外部門檻分開記錄，填完範本不等於宣告第一版完成。
