# 第一版驗收補充

此頁記錄凍結第一版驗收後，使用者明確變更的範圍。原始 `ACCEPTANCE.md`、`REQUIREMENTS.json` 與歷史測試保留；判讀目前門檻時，以下已確認的變更優先。這不是允許實作者自行放寬測試。

## 2026-10-28：正常顯示比例

使用者確認：「不需要驗證原生 200% 縮放。這個比例太極端了，我們只要確保正常比例下可以使用即可。」

- 移除 V1-UX-05 中「原生瀏覽器 200% 縮放」的交付前真人驗證門檻，後續不再排程該測試，也不將其列為等待使用者的必要項目。
- 目前以正常 100% 顯示比例下的可讀性、主要控制可達性、版面與操作驗收。既有響應式／鍵盤／焦點／Reduced Motion 自動回歸及歷史結果保留。
- 第一人稱進入／移動／滑鼠鎖定／安全退出與真實裝置聽測的需求仍有效。自動測試不能代替這些真人觀察。
- 此變更沒有把未執行的原生 200% 測試標示成 PASS，也沒有宣告整體第一版完成。

## 2026-11-01：第一人稱滑鼠操作與直接建造

使用者在 R20 真人測試的 B5 回報：「建造模式非常不直覺……我不應該需要點擊確認之後才可以繼續建造或操作物件，我應該要可以直接操作的。……進入建造模式之後我就沒辦法退出建造模式了」，並要求「左鍵點擊皆可以直接抓取物件，右鍵可以建造，不需要使用E或是B這類的快捷鍵」。使用者另選定：持有時左鍵投擲、右鍵放下；按住右鍵預覽、放開放置；空中放置的物件停在空中但仍可碰撞。完整回報見 [R21 使用者回報](USER_TEST_FEEDBACK_20261101-r21.json)。

- 取代 V1-BLD-01 與 V1-CON-05 的「geometry ack 後顯式 Enable，另行 Resume」：放開右鍵即放置。內部仍依 Ghost → PlacementPending → Staged → Active 執行，geometry ack 前沒有 active body、collider 或聲源，重新驗證與重疊拒絕不變；ack 後自動啟用，不需使用者確認。放置前模擬正在運算且期間沒有其他暫停原因時，模擬維持運算。失敗時回復交易，不留下半建立或停用的物件，也不需要隱藏按鈕才能離開。每次放開右鍵只建立一個物件。
- 取代 `docs/05-ux/FPS_INTERACTION_UX.md` 輸入映射中 `throw`＝左鍵、`toggleBuild`＝B、`ghostPlace`＝左鍵與 `ghostCancel`＝右鍵：沒持有時左鍵抓取，按住右鍵預覽、放開放置；持有時左鍵投擲，右鍵放下（與 Drop 同語意）。預覽期間按左鍵或 Esc 取消。E、G、F、R、L 保留為選用快捷鍵，不需要 B 或建造模式。
- 修改 V1-PHY-06 對 ghost 的保存：按住右鍵的預覽是暫時輸入，Esc、失焦、失去滑鼠鎖定或暫停會取消預覽且不放置。Held 的保存規則不變。
- 新增空中放置：準星在預覽距離內沒有命中表面時，物件放在視線方向的預覽距離處，預設為 `dynamicNoGravity`；貼表面放置維持草稿的模式。完整形狀查詢的重疊拒絕與 3.5 m 範圍上限不變。
- 新增：第一人稱操作提示移到 viewport 底部的提示列，不遮住準星與畫面中央，並依情境列出實際按鍵。
- 取得滑鼠鎖定的那次點擊（左右鍵皆是）不得抓取、投擲或放置；不鎖定滑鼠的輔助操作仍提供等效按鈕。
- 此變更沒有把任何項目標成 PASS；B5 需在實作後由使用者重測。

## 2026-11-01：主頁面說明文字改為懸浮提示

使用者要求：「為所有參數的詳細設定寫一個Documentation，然後刪除專案本體頁面中的所有說明文字，或者是讓這些說明文字作為替代文字，當滑鼠懸浮在上面時再顯示。」

- 主頁面不再顯示整段說明文字；靜態說明改為欄位或標題旁的懸浮提示，滑鼠懸停與鍵盤聚焦都能開啟，Esc 關閉，並以 `aria-describedby` 提供給輔助技術。停用控制的原因也必須能以聚焦取得。
- 欄位名稱、數值與單位、動態狀態、錯誤、拒絕原因、安全與音量警告，以及「Synthetic」「數值近似」等簡短證據標籤維持可見；設計系統「提示不得是必要資訊的唯一來源」仍適用於這些項目。
- 每個參數的單位、範圍、預設值與作用集中在[參數設定參考](PARAMETER_REFERENCE.md)。
- 此變更沒有把觸控或螢幕閱讀器操作標成 PASS。
