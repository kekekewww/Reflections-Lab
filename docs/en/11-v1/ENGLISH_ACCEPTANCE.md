# Supplementary Acceptance for the English Version

Following the [new user requirement](../00-project/V1_ENGLISH_VERSION_REQUEST_20261027.md), this page adds language-layer acceptance; the original [51-item matrix](ACCEPTANCE.md) and protected contracts/tests remain unchanged. Results must cite the actual new bundle and browser; the presence of a translation dictionary does not establish a pass.

| ID | Pass Conditions | Direct Evidence |
| --- | --- | --- |
| EN-01 | Traditional Chinese is the default; the visible Traditional Chinese/English selector, document.lang, and local preference agree. Reload preserves the selection, and invalid or unavailable storage safely falls back to the default. | Selection/reload in a real browser and bounded negative preference cases. |
| EN-02 | The main Workspace, Inspector, Sound curves/overrides, FPS/building, assets/import, capture/replay/A-B, and fixed AI interface and accessible names are available in English. Known states/errors have English text; unknown raw backend diagnostics clearly identify their source and retain stable codes without hiding errors. User object/project/asset names remain in their original language. | Real English operation flows, fixed text/aria checks, known-error and raw-diagnostic cases; translation review. |
| EN-03 | Switching languages does not dispatch model calls or scene commands, change Project/Scene/Behavior/asset pins/SI values, recreate Canvas or AudioContext, or reset run/tick/native voice. Raw/invalid drafts being edited are retained. | Before/after document/identity/clock and draft checks in the real runtime, distinguishing natural computation progress from language changes. |
| EN-04 | English is readable and controls are reachable on desktop and at 320 CSS px, with no new overflow/obstruction; existing keyboard, focus, reduced motion, and input arbitration behavior is retained. | Real browser screenshots and visual inspection, keyboard/layout tests; native zoom is still recorded separately under the original matrix. |
| EN-05 | The English README/user guide matches the actual CLI, language selection, and workflows, and explicitly identifies approximation/Synthetic/Computed, offline and real Meta provenance, the default paid-call gate, and NOT RUN/external gates. | Cross-checks against package scripts/actual interface/evidence; no claims that hearing, SPL, unverified models, or complete quality have passed. |
| EN-06 | All project narrative documentation has a complete English version or an explicit already-English mapping, covering architecture/research/acceptance/Agents/Skills/Wiki and history. Canonical sources, hashes, timestamps, and rights are retained; translation cannot change scientific conditions/values/validation statuses. English links locate translations or shared data; stale translations are detectable when originals change, and indexes/placeholders cannot replace translations. | Full-file inventory/source and translation hashes/link and completeness checks, partitioned translation and independent fidelity review; generated data, original third-party full texts, and already-English documents are explicitly classified. |

English localization belongs to presentation; technical IDs, APIs, file paths, and data are not translated. New acceptance results reconnect to the existing Task0016/Wiki/handoff rather than creating a second task system.
