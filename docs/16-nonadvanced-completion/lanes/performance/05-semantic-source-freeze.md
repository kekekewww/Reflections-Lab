# 瀏覽器語義 pilot 來源凍結（版本 1）

此收據只凍結獨立 24 callback／13 group 控制頁、純 oracle、原生 trace 比對及 55 秒 owned-child 命令。尚未執行真瀏覽器、尚無新資格 registry，正式 600 秒仍為 NOT RUN。原 V3 launcher／producer 資格 pin、負載、數值核心及門檻均未修改。

最終來源的 102 項純測試全通過；scope lint 0 error／0 warning；命令 --plan 只輸出限制。原始輸出與精確 source pins 見 semantic-source-freeze-v1.json。RED 原始錯誤保留於 semantic-boundary-cleanup-red-r1.tap；缺少 API 時 guard 未執行的新 assertion 不算 RED 覆蓋。初始 native／journal 的獨立負例測試與真實 trace 證據分開。

控制頁保存原生 RAF／cancel identity，原始 journal 與原 V3 collector 同時記錄；原生 validator 仍執行原 strict parser，獨立 oracle 再核對完整 handle 集合、時間窗、cancel、pretrace pending 與 custom mark。每次真 run 將封存實際 served bytes、trace 與 Browser.getVersion／可執行檔／CPU／GPU 欄位。未請求音訊，取樣率及設備 block 一律 null。

Deadline 於 factory 開始前及 await 完成後都檢查。清理各操作最多一秒，共用八秒並預留兩秒寫收據；最後要求實際 browser disconnected、server listening=false、restoration 及 source／executable endpoints。Windows watchdog 的 direct-child close 不當作整 process tree 已終止：若 forced stop 缺少 tree proof，machineLeaseReleasable=false，需保留機器 lease 並向 Root 回報，不能宣稱已釋放。

獨立 source review 未見剩餘 P1；這是碼審結果，不是 browser 語義資格通過。下一個已排程硬體窗口先保留原 launcher 的拒收，再執行此 pilot；是否建立新資格版本須依實際原始證據獨立 review。
